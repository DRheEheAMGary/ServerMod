# 钓竿系统（方案 · 未实现）

> 状态：**设计定稿；第 1 步（数据契约）已在 0.5.0 落地** —— 见 `common/rod/`：部件表 + 属性公式 + NBT 线格式，自检守着。
> 相关：[自定义物品](自定义物品.md)（部件外观 / 资源包）、[配置说明](配置说明.md)、[客户端模组方案](客户端模组方案.md)（双端渲染）。
> 本文是实现依据：**做什么、怎么算、怎么验**。实现时按"施工顺序"逐条落地，并在自检里加对应断言。

## 0. 总原则

- **部件用原版材料**，唯一例外是**地狱丝线**（`hubsuite:nether_string`，已有物品）；
- 装配对象就是**原版钓竿** `minecraft:fishing_rod`：部件 / 升级 / 耐久全部写在**它的数据组件**里 → **不需要新钓竿物品、不需要 Polymer 造物品**；
- **删掉 `hubsuite:lava_rod`**："能不能在岩浆里钓"改由**钩**决定（岩浆渔获表 / 岩浆粒子 / 免火这些已做好的部分全部保留）；
- 小数一律**整数编码**：乘数 ×10（`15` = ×1.5）、概率 ×1000（`7` = 0.7%），**计算过程不取整**；
- 玩法**全部在服务端**；客户端模组只是可选的"表现层增强"（见客户端模组方案）。

## 1. 部件与数值（定稿）

## 2. 属性计算

`~
耐久上限 = 杆.耐久基础 × 线.耐久乘数 × Π(升级耐久乘数) + Σ(升级耐久数值)
速度     = 线.速度乘数 × 钩.速度乘数 × Π(升级速度乘数)
幸运     = (基础幸运 + Σ幸运数值) × Π(幸运乘数)
断线概率 = 线.断线概率                    // 只看线，与升级/耐久无关
岩浆可钓 = 钩 ∈ {黑曜石, 下界合金}
`~

- 全程用整数（×10 / ×1000）算，**不取整**；耐久上限**下限夹到 1**（青金石 −192 配木杆 64 会算出负数）；
- 耐久存"当前 / 上限"两个 **×10 整数**（512.5 → 5125），tooltip 显示 1 位小数；
- 原版那条耐久条是整数，所以按**比例**映射到原版的 MAX_DAMAGE / DAMAGE（只影响观感）。

## 3. 装配台

### 3.1 合成表

`~
空     钓竿   空
木板   铁锭   木板
木板   工作台 木板
`~

→ 1 钓竿 + 1 铁锭 + 1 工作台 + 4 木板 = **装配台 ×1**

### 3.2 交互规则

- **放上去就消失**：往部位格放材料 → **立刻消耗 1 个**并生效 → 格子回到空（不存东西、不做虚影）；
- **放错部位**（线放进钩位）→ 拒绝，材料留在光标上；
- **杆位**：
  - 同种材料 + 耐久未满 → **修满**（消耗 1 个）；
  - 不同种材料 → **换底**：耐久基数换成新杆的，**当前耐久也回满**（全新）；
  - 耐久已满 + 同种材料 → 拒绝（不浪费材料）；
- **线位 / 钩位**：只换属性，**不影响耐久**，各消耗 1 个；
- 钓竿：手持右键装配台放入，或直接在界面里放/取；**关界面时自动还给玩家**（背包放不下就掉在台子旁）—— *待定项，见第 9 节*；
- 方块被破坏 → 台子里的钓竿掉出来。

### 3.3 界面怎么实现（**0.5.0 已落地：自定义菜单 + 自定义界面**）

> 下面那节「借壳」是**没有客户端模组时**的办法，现在**已作废**（留档）。
> 实际做法：`common/rod/AssemblyMenu`（4 个语义格）+ 客户端 `AssemblyScreen`；
> 26.1 把 `MenuScreens` 私有化了（`register` 是 private、`ScreenConstructor` 是包私有，
> Fabric 也没替代入口），所以客户端用 `MenuScreensMixin` 在 `MenuScreens.create` 头部
> 拦下自己的菜单类型、建自己的界面。规则（修补 / 换底 / 换线 / 换钩）抽成纯函数
> `common/rod/AssemblyRules`，由自检直接测（12 组）。

#### 附：没有客户端模组时的借壳方案（作废，留档）

原版客户端只认原版菜单，所以必须借壳。**不需要虚影**：附魔台的青金石图标、锻造台的模板/材料轮廓，本来就是**画在 GUI 底图上**的。

| 借的壳 | 槽位 | 底图 | 副作用 |
|---|---|---|---|
| **合成器 `crafter`** | 3×3 全可放 + 1 结果格 | **独立** `crafter.png` | **只影响合成器界面**（1.21 新方块，很少打开）← 推荐 |
| 潜影盒 | 27 全可放 | 独立 `shulker_box.png` | 所有潜影盒界面变样 |
| 漏斗 | 5 全可放 | 独立 `hopper.png` | 漏斗界面变样 |
| 通用容器 `GENERIC_9xN` | 9~54 | **共用** `generic_54.png` | **所有箱子/木桶/末影箱**变样 ✗ |
| 锻造台 | 模板位只收真模板 ✗ | 独立 | 槽位限制卡死 ✗ |

**已验证**（26.1 客户端 jar）：`ContainerScreen`（所有尺寸的箱子）只有一张底图 `textures/gui/container/generic_54.png`，按行数裁剪；其它容器各有独立底图。

推荐布局（借合成器）：3×3 网格里 **左中 = 钓竿位**、**右列三格 = 杆 / 线 / 钩**；合成器自带的结果格留空，底图上画成装饰。

**必须堵的两个洞**（借壳代价，服务端处理）：
1. 3×3 不能变成"免费工作台" → 接管 `slotsChanged`，**永不产出合成结果**；
2. 非语义格 → 服务端**拒绝放/取**。

### 3.4 外观（已在 0.5.0 落地：客户端分层渲染）

**不再需要 120 个组合模型** —— 客户端模组用原版模型系统**运行时叠层**：

- 服务端把 4 个材质 id 写进 `custom_model_data` 的字符串槽（`RodData.modelHint()`）；
- 客户端 `assets/minecraft/items/fishing_rod.json` 对 index 0/1/2/3 各做一次 `minecraft:select`，
  再用 `minecraft:composite` 把四层叠起来；认不出的材质落 `fallback`（占位图）—— 这就是"未知即占位"，
  由原版模型系统实现，我们一行渲染代码都没写；
- 现在 17 张贴图 / 17 个模型都是**脚本生成的占位图**（每层用不同颜色区分，方便肉眼确认叠层对不对），
  等美术画好真图直接替换同名文件即可；
- 升级那一层的 fallback 是 `minecraft:empty`（没升级就不画）。

装配台底图：仍待定（0.6 做界面时一起）。

## 4. 升级（走原版铁砧，**0.6 已实现**：`feature/RodAnvil` + `AnvilRodUpgradeMixin`）

- 「钓竿 + 升级物」→ 输出打了该升级的竿；**只有一个升级槽**，再来一个**直接替换**（旧的消失，不退还）；
- 原版**累计惩罚（Prior Work Cost）**原样生效 → 平衡性来源；
- 升级物都是原版物品：钻石 / 绿宝石 / 青金石 / 红石。

| 升级 | 耐久 | 速度 | 幸运 | 附魔 |
|---|---|---|---|---|
| 钻石 | 乘数 ×1.2（12） | 乘数 ×1.5（15） | 数值 +2 | — |
| 绿宝石 | 数值 **+768** | — | 乘数 ×1.5（15） | — |
| 青金石 | 数值 **−192** | — | 乘数 **×2.5（25）** | 15 级 → **30 级** + 宝藏附魔概率↑ |
| 红石 | 乘数 ×0.8（8） | 乘数 **×3.0（30）** | — | — |

## 5. 断线 / 损坏（**0.6 已实现**：`feature/RodFishing` + `RodData.damage/applyVanillaBar`）

- **断线**：咬钩成功后掷 `线.断线概率` → 中：**空手而归 + 扣饵 + 耐久 −3 + 播放原版"装备损坏"音效**；
- **损坏**：耐久 ≤ 0 → **不能钓**（物品不消失，模型切"裂了" —— **模型这半已在 0.5.0 实现**：
  渲染提示第 5 槽写 `broken`，客户端多叠一层裂纹；"不能钓"属于 0.6 的玩法逻辑）；恢复只能回装配台（杆位放同种材料修补，或换底）；
- 线 / 钩 的替换**不影响耐久**。

## 6. 青金石附魔（**0.6 已实现**：`feature/RodEnchanting` + `hubsuite.accesswidener`）

- 青金石升级：按**附魔台 30 级**等价 + **有概率追加一个宝藏型附魔**；

## 7. 施工顺序与自检点

1. ✅ **材质/升级清单 + 属性公式 + 自检**（0.5.0 已落地：`common/rod/RodMaterials` + `RodData`；数值仍可实机调）
   - 自检：部件表数值 13 项、属性公式 12 组（含耐久下限 1）、物品→材质匹配 9 组、NBT 往返 + 键集合 + 编码稳定性
2. **装配台**：方块 + 方块实体 + 借壳 + 4 个语义格 + 放材料即消耗/替换/修补 + 关界面还竿 + 堵免费合成
   - 自检：替换、修补、换底、放错拒绝、关界面还竿、破坏掉落、非语义格拒绝
3. **铁砧升级**：注入 `AnvilMenu` + 单槽直接替换 + 惩罚
   - 自检：升级生效、二次升级顶掉旧的、惩罚增长、非法组合无结果
4. **断线 + 损坏**
   - 自检：概率 0 / 1 两个极端、扣饵与 −3、损坏后不能钓、装配台修复
5. **青金石附魔**
   - 自检：15 / 30 级差异、宝藏附魔只在青金石出现、诅咒不出现
6. **删掉熔岩钓竿**：岩浆判定改看钩 + 清理配方/贴图/自检特判
7. **资源包**：12 张部件贴图 + 120 个组合模型（脚本生成）+ 装配台底图
