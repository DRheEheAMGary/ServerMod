# HubSuite 配置说明

配置文件位置：**`config/hubsuite/config.json`**
修改后执行 `hub reload`（部分设置热生效），**世界增删需要重启服务端**。

> 配置是"运维的唯一真相来源"：这里显式写出的 gamerule 会覆盖存档里的值，
> 每次启动都会重新应用。

---

## 顶层结构

```json
{
  "configVersion": 1,
  "lobby":  { ... },      // 大厅
  "auth":   { ... },      // 登录/注册
  "island": { ... },      // 空岛系统
  "servers": [ ... ]      // 子服列表（可任意增删）
}
```

---

## `lobby` —— 大厅

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `saveName` | string | `hubsuite_lobby` | 大厅存档目录名 |
| `dimensionType` | string | `minecraft:the_end` | 维度类型。末地天然无天气、无自然生成，适合做大厅 |
| `voidGenerator` | bool | `true` | 是否用纯虚空生成器覆盖地形 |
| `seed` | long | `0` | 世界种子 |
| `spawnX/Y/Z` | double | `0.5/100/0.5` | 出生点坐标 |
| `spawnYaw/Pitch` | float | `0/0` | 出生朝向 |
| `invulnerable` | bool | `true` | 大厅内禁止一切伤害 |
| `clearInventory` | bool | `true` | 进入大厅清空背包（大厅不携带物品） |
| `adventureMode` | bool | `true` | 强制冒险模式 |

> 假人 NPC 的坐标是**各自子服**配置里的 `npc.x/y/z`，且是相对大厅坐标系的。

---

## `auth` —— 登录 / 注册

| 字段 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 关闭后所有人直接进入，不做认证 |
| `loginTimeoutSeconds` | `120` | 未登录超时踢出（秒） |
| `sessionMinutes` | `60` | 会话保持时长。同 UUID + 同 IP 在此时间内免登录；`0` = 每次都要登录 |
| `maxFailures` | `5` | 连续失败多少次后锁定 |
| `lockoutMinutes` | `10` | 锁定时长（分钟） |
| `minPasswordLength` | `6` | 密码最短长度 |
| `maxPasswordLength` | `32` | 密码最长长度（上限受对话框输入框限制，最大 255） |
| `pbkdf2Iterations` | `120000` | PBKDF2 迭代次数，调高更安全但登录更慢 |
| `allowMultipleAccountsPerIp` | `true` | 是否允许同 IP 注册多账号（离线服建议保留 true） |

**安全说明**：密码以 `pbkdf2-sha256$迭代次数$盐$哈希` 形式存进 SQLite，
每账号独立 16 字节随机盐，校验用常量时间比较。
表单提交走对话框的 NBT 负载通道，**不经过聊天、不经过命令、不写日志**。

---

## `servers[]` —— 子服列表

这是本模组"可扩展"的核心：**加一个子服 = 加一条配置，不用写代码**。

### 基础字段

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，同时是存档目录名（`hubsuite_<id>`）与命令参数（`/hub <id>`）。只允许 `a-z0-9_-`，最长 48 |
| `displayName` | 显示名，支持 `&` 颜色代码 |
| `enabled` | 是否启用（`false` 时不建世界、不出现在列表里） |
| `order` | 排序，越小越靠前 |

### 世界生成

| 字段 | 说明 |
|---|---|
| `worldKind` | `normal` 原版地形 / `flat` 超平坦 / `void` 纯虚空 |
| `flatLayers` | 仅 `flat` 生效。从下往上的层，格式 `方块id*高度`，如 `["minecraft:bedrock*1","minecraft:grass_block*3"]` |
| `seed` | 世界种子 |
| `spawnX/Y/Z`、`spawnYaw/Pitch` | 该子服的出生点 |

### 规则

| 字段 | 说明 |
|---|---|
| `gameRules` | 原版 gamerule，**键名用常量名**（见下表），只写想改的项 |
| `behaviour` | mod 自有的子服规则（见下） |
| `difficulty` | `peaceful` / `easy` / `normal` / `hard` |
| `gameMode` | `survival` / `creative` / `adventure` / `spectator` |
| `forceGameMode` | 每次进入是否强制设置该模式 |
| `allowGameModeCommand` | 是否允许玩家用 `/gamemode` 自己切换 |

**常用 gamerule 常量名**（26.1 的命名，跟旧版不一样）：

| 常量名 | 含义 |
|---|---|
| `KEEP_INVENTORY` | 死亡保留物品 |
| `PVP` | 玩家间伤害 |
| `FALL_DAMAGE` | 摔落伤害 |
| `MOB_GRIEFING` | 生物破坏方块 |
| `TNT_EXPLODES` | TNT 是否爆炸 |
| `FIRE_SPREAD_RADIUS_AROUND_PLAYER` | 火焰蔓延半径（**整数，0 = 不蔓延**） |
| `SPAWN_MONSTERS` / `SPAWN_MOBS` | 生成怪物 / 生物 |
| `ADVANCE_WEATHER` | 天气变化 |
| `SHOW_DEATH_MESSAGES` | 死亡消息 |
| `IMMEDIATE_RESPAWN` | 立即重生 |
| `RESPAWN_RADIUS` | 重生半径 |

> 完整列表在游戏里执行 `/gamerule` 查看；配置里写未知名字只会告警，不会导致启动失败。
> 管理员用 `/gamerule` 改过的值会被保存到 `config/hubsuite/rules/<id>.json`，重启后依然有效。

### `behaviour` —— mod 自有规则

| 字段 | 默认 | 说明 |
|---|---|---|
| `pvp` | `false` | 玩家间伤害（与 gamerule `PVP` 取"与"） |
| `invulnerable` | `false` | 完全无敌 |
| `fallDamage` | `true` | 摔落伤害 |
| `explosionBlockDamage` | `true` | 爆炸破坏地形 |
| `fireSpread` | `true` | 火焰蔓延 |
| `mobGriefing` | `true` | 生物破坏方块 |
| `tntIgnition` | `true` | TNT 是否爆炸 |
| `allowItemDrop` | `true` | 允许丢弃物品 |
| `allowFlight` | `false` | 允许飞行 |
| `clearInventoryOnEnter` | `false` | 进入时清空背包 |
| `keepHungerFull` | `false` | 保持满饥饿 |
| `worldBorderRadius` | `0` | 世界边界半径（`0` = 用服务端默认） |

> 这些开关会**同步**成对应的原版 gamerule（`pvp`→`PVP`、`fallDamage`→`FALL_DAMAGE`…），
> 所以管理员用 `/gamerule` 看到的值与实际行为一致，不会困惑。

### 玩家与权限

| 字段 | 默认 | 说明 |
|---|---|---|
| `rememberLastLocation` | `true` | 再次进入时回到上次退出的位置 |
| `permissionGroup` | `hubsuite.<id>` | 权限组名（接 LuckPerms 用） |
| `huskhomesTeleport` | `true` | 是否允许在该子服用 HuskHomes 的传送指令。**空岛服/创造服建议 `false`**，否则 `/home` 会把人传出保护范围 |

### `npc` —— 大厅假人

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 是否生成 |
| `x/y/z`、`yaw/pitch` | —— | 在大厅坐标系里的位置与朝向 |
| `name` | 空 | 头顶名字（空 = 用 `displayName`），支持 `&` 颜色代码 |
| `skin` | `auto` | `auto` = 按名字拉正版皮肤；也可填具体正版玩家名；`none` = 默认皮肤 |
| `lookAtNearestPlayer` | `true` | 是否转头看最近的玩家 |

## `island` —— 空岛系统

| 字段 | 默认 | 说明 |
|---|---|---|
| `serverId` | `skyblock` | 挂在哪个子服上（对应 `servers[].id`） |
| `plotSize` | `256` | 每座岛的方格边长 |
| `plotGap` | `32` | 方格之间的间隔，避免两岛相连 |
| `islandY` | `100` | 岛屿高度 |
| `islandOffsetX/Z` | `0` | 岛中心相对方格中心的偏移 |
| `protectPlots` | `true` | 方格保护（非岛主不能破坏/放置） |
| `voidY` | `0` | 掉到该高度以下视为掉虚空 |
| `autoCreateOnFirstJoin` | `true` | 首次进入自动分配并生成一座岛 |
| `defaultType` | `classic` | 默认岛型 |

### `island.types[]` —— 岛型

| 字段 | 说明 |
|---|---|
| `id` | 唯一 id（`/island create <id>` 用） |
| `displayName` | 显示名，支持颜色代码 |
| `description` | 选择界面的简介 |
| `layers` | 方块层，格式 `y偏移:方块id`，如 `"0:minecraft:grass_block"`、`"-1:minecraft:dirt"` |
| `beach` | 岸边的沙滩方块（只有海岛用得上）。写 `none` 表示不要沙滩 |
| `tree` | 是否生成一棵树 |
| `chest` | 是否生成初始物资箱 |
| `loot` | 箱子物资，格式 `物品id*数量` |

内置两种：

- **`classic` 经典空岛** —— 草方块岛 + 橡树 + 冰/岩浆/树苗/骨粉
- **`ocean` 海岛** —— 不规则圆岛（草地 + 沙滩环 + 水下缓坡，底下填到海床）+ 钓鱼竿/船/海带/甘蔗

## 一个完整的子服配置示例

```json
{
  "id": "minigame",
  "displayName": "&d小游戏服",
  "enabled": true,
  "order": 10,
  "worldKind": "flat",
  "flatLayers": ["minecraft:bedrock*1", "minecraft:stone*2", "minecraft:sand*1"],
  "seed": 12345,
  "spawnX": 0.5, "spawnY": 4.0, "spawnZ": 0.5,
  "spawnYaw": 0.0, "spawnPitch": 0.0,
  "gameMode": "adventure",
  "difficulty": "peaceful",
  "forceGameMode": true,
  "allowGameModeCommand": false,
  "rememberLastLocation": false,
  "huskhomesTeleport": false,
  "permissionGroup": "hubsuite.minigame",
  "gameRules": {
    "KEEP_INVENTORY": "true",
    "SPAWN_MOBS": "false",
    "SPAWN_MONSTERS": "false",
    "FALL_DAMAGE": "false",
    "ADVANCE_WEATHER": "false",
    "SHOW_DEATH_MESSAGES": "false"
  },
  "behaviour": {
    "pvp": false,
    "invulnerable": true,
    "fallDamage": false,
    "explosionBlockDamage": false,
    "fireSpread": false,
    "mobGriefing": false,
    "tntIgnition": false,
    "allowItemDrop": false,
    "allowFlight": true,
    "clearInventoryOnEnter": true,
    "keepHungerFull": true,
    "worldBorderRadius": 256.0
  },
  "npc": {
    "enabled": true,
    "x": 8.5, "y": 100.0, "z": 0.5,
    "yaw": 90.0, "pitch": 0.0,
    "name": "&d小游戏服",
    "skin": "auto",
    "lookAtNearestPlayer": true
  }
}
```

加完这条、重启服务端，大厅里就会多出一个假人，`/hub minigame` 也能直接进。
**全程不需要改任何 Java 代码。**
