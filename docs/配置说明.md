# 配置说明

主配置在 **`config/hubsuite/config.json`**。它由模组首次启动时生成，改完**重启服务端**生效
（世界增删必须重启；规则类改动可重连测试）。

> 容错：解析失败时模组会把坏文件备份成 `config.json.broken-<毫秒时间戳>` 并回落默认配置；
> 保存是原子写（先写 `config.json.tmp` 再 move），不会写坏原文件。

## 顶层

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `configVersion` | int | `1` | 配置结构版本，将来迁移用 |
| `lobby` | object | 见下 | 大厅配置 |
| `auth` | object | 见下 | 登录 / 注册配置 |
| `servers` | array | survival / creative / skyblock | 子服列表，可任意增删 |
| `island` | object | 见下 | 空岛系统（挂在 `island.serverId` 指定的子服上） |
| `quests` | object | 见下 | 任务系统 |
| `update` | object | 见下 | 更新检查 |

## `lobby` — 大厅

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `saveName` | string | `hubsuite_lobby` | 大厅存档目录名 |
| `dimensionType` | string | `minecraft:overworld` | 大厅维度类型。**不要用 `minecraft:the_end`**：会强制黑曜石平台 + 末影龙并覆盖出生点；要虚空就配合 `voidGenerator` |
| `voidGenerator` | bool | `true` | 用纯虚空生成器覆盖地形（只保留维度属性） |
| `seed` | long | `0` | 世界种子 |
| `spawnX` / `spawnY` / `spawnZ` | double | `0.5` / `100.0` / `0.5` | 出生点坐标 |
| `spawnYaw` / `spawnPitch` | float | `0.0` / `0.0` | 出生朝向 |
| `invulnerable` | bool | `true` | 大厅内禁止一切伤害 |
| `adventureMode` | bool | `true` | 强制冒险模式 |
| `buildPlatform` | bool | `true` | 出生点自动生成带灯光的平台（否则玩家站在虚空里） |
| `platformRadius` | int | `10` | 平台半径（方块） |
| `menuNpc` | object / null | 默认生成并 `enabled=true` | 大厅引导假人（点击打开服务器选择界面）；坐标是**相对大厅出生点的偏移**，默认 `x=0,y=0,z=5,yaw=180,name="§a§l点击传送"` |

## `auth` — 注册 / 登录

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `enabled` | bool | `true` | 关闭后所有人直接进入，不做认证 |
| `loginTimeoutSeconds` | int | `120` | 未登录超时踢出（秒） |
| `sessionMinutes` | int | `60` | 会话保持时长（分钟）；同 UUID + 同 IP 在此时间内免登录；`0` = 每次都要登录 |
| `maxFailures` | int | `5` | 连续失败多少次后锁定 |
| `lockoutMinutes` | int | `10` | 锁定时长（分钟） |
| `minPasswordLength` | int | `6` | 密码最短长度 |
| `maxPasswordLength` | int | `32` | 密码最长长度 |
| `pbkdf2Iterations` | int | `120000` | PBKDF2 迭代次数（下限 10000） |
| `allowMultipleAccountsPerIp` | bool | `true` | 是否允许同 IP 注册多账号（离线服建议 `true`） |

密码以 `pbkdf2-sha256$迭代次数$盐$哈希` 存入 SQLite，每账号独立 16 字节随机盐；
表单走对话框 NBT 负载通道，**不进聊天、不进命令、不进日志**。

## `servers[]` — 子服

### 基础字段

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `id` | string | `survival` | 唯一标识；同时是存档目录名与 `/hub` 参数。只允许 `a-z0-9_-`，最长 48，重复会被跳过 |
| `displayName` | string | `&a生存服` | 显示名，支持 `&` 颜色代码 |
| `enabled` | bool | `true` | `false` 时不建世界、不出现在列表 |
| `order` | int | `0` | 排序，越小越靠前 |

### 世界生成

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `worldKind` | string | `normal` | `normal` 原版地形 / `flat` 超平坦 / `void` 纯虚空 |
| `flatLayers` | string[] | `["minecraft:bedrock*1"]` | 仅 `flat` 生效；从下往上，格式 `方块id*高度` |
| `ownNether` | bool | `true` | 该子服独立下界；关掉退回原版全服共用 |
| `ownEnd` | bool | `true` | 该子服独立末地 |
| `seed` | long | `0` | 世界种子；默认三服分别为 20260101 / 20260202 / 20260303。同种子的多个 `normal` 子服会被自动分配不同候选值并告警 |
| `useWorldSpawn` | bool | `true` | 用世界自身地形出生点（`normal` 建议 `true`，`flat` / `void` 需 `false`） |
| `spawnX` / `spawnY` / `spawnZ` | double | `0.5` / `64.0` / `0.5` | 该子服出生点（`useWorldSpawn=false` 时用） |
| `resolvedSpawnX/Y/Z`、`resolvedSpawnSeed` | — | 自动写回 | 出生点缓存，避免 level.dat 读回悬空 Y；换种子自动失效重算 |

### 规则

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `gameRules` | map | `{}` | 原版 gamerule，键名用大写常量名（如 `KEEP_INVENTORY`），只写想改的项 |
| `difficulty` | string | `normal` | `peaceful` / `easy` / `normal` / `hard` |
| `gameMode` | string | `survival` | `survival` / `creative` / `adventure` / `spectator` |
| `forceGameMode` | bool | `false` | 每次进入是否强制设置该模式 |
| `allowGameModeCommand` | bool | `false` | 是否允许玩家用 `/gamemode` 自行切换 |

规则改完落盘到 `config/hubsuite/rules/<子服id>.json`，重启仍有效。写未知 gamerule 名只告警不失败。

### `behaviour` — 模组自己的规则

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `pvp` | bool | `false` | 玩家间伤害（与 gamerule PVP 取「与」） |
| `invulnerable` | bool | `false` | 完全无敌 |
| `fallDamage` | bool | `true` | 允许摔落伤害 |
| `explosionBlockDamage` | bool | `true` | 爆炸破坏地形 |
| `fireSpread` | bool | `true` | 火焰蔓延 |
| `mobGriefing` | bool | `true` | 生物破坏方块 |
| `tntIgnition` | bool | `true` | TNT 是否爆炸 |
| `allowItemDrop` | bool | `true` | 允许丢弃物品 |
| `allowFlight` | bool | `false` | 允许飞行 |
| `clearInventoryOnEnter` | bool | `false` | 进入时清空背包 |
| `keepHungerFull` | bool | `false` | 保持满饥饿 |
| `worldBorderRadius` | double | `0.0` | 世界边界半径，`0` = 用服务端默认 |

> `behaviour` 比 gamerule 更早生效，且能做到 gamerule 做不到的事（如禁止爆炸破坏方块）。

### 玩家与权限

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `rememberLastLocation` | bool | `true` | 再次进入回到上次退出位置（`false` = 回出生点） |
| `permissionGroup` | string | `hubsuite.survival` | 权限组前缀（接 LuckPerms） |
| `huskhomesTeleport` | bool | `true` | 是否允许在该子服用 HuskHomes 传送指令（默认全开）。**家（`/home`）按子服隔离**：生存服设的家，在创造服/空岛服看不到也用不了 |

### `npc` — 假人

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `enabled` | bool | `true` | 是否生成 |
| `x` / `y` / `z` | double | `0.0` / `0.0` / `5.0` | **相对所在维度出生点的偏移**（不是绝对坐标） |
| `yaw` / `pitch` | float | `0.0` / `0.0` | 朝向 |
| `name` | string | `""`（空 = 用 `displayName`） | 头顶名字，支持 `&` 颜色代码 |
| `skin` | string | `auto` | `auto` 按名字拉正版皮肤；也可填正版玩家名；`none` = 默认皮肤 |
| `lookAtNearestPlayer` | bool | `true` | 是否转头看最近玩家 |

## `update` — 更新检查

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `check` | bool | `true` | 是否检查更新（总开关） |
| `checkBeta` | bool | `false` | 是否也检查测试版（预发布）；`check = false` 时本项无效 |

启动时**异步查一次** GitHub Releases。发现比当前版本新的版本时，控制台打印一行，
管理员上线时会收到一条聊天提示。**不会自动下载或替换 jar。**

- 请求失败（离线 / 被墙 / 限流）**静默忽略**，不影响启动；
- 结果缓存在 `config/hubsuite/update-check.json`，24 小时内不重复请求；
- 用 ETag 条件请求，命中 304 时**不消耗** GitHub 的 60 次/小时限流。

> 只检查更新、不会自动安装。升级仍需手动替换 `mods/` 里的 jar。

## 完整子服示例（小游戏服）

```json
{
  "id": "minigame",
  "displayName": "&d小游戏服",
  "enabled": true,
  "order": 10,
  "worldKind": "flat",
  "flatLayers": ["minecraft:bedrock*1", "minecraft:stone*2", "minecraft:sand*1"],
  "seed": 12345,
  "useWorldSpawn": false,
  "spawnX": 0.5, "spawnY": 4.0, "spawnZ": 0.5,
  "gameMode": "adventure",
  "difficulty": "peaceful",
  "forceGameMode": true,
  "allowGameModeCommand": false,
  "rememberLastLocation": false,
  "huskhomesTeleport": true,
  "permissionGroup": "hubsuite.minigame",
  "gameRules": {
    "KEEP_INVENTORY": "true",
    "SPAWN_MOBS": "false",
    "ADVANCE_WEATHER": "false"
  },
  "behaviour": {
    "pvp": false, "invulnerable": true, "fallDamage": false,
    "explosionBlockDamage": false, "allowFlight": true,
    "clearInventoryOnEnter": true, "keepHungerFull": true,
    "worldBorderRadius": 256.0
  },
  "npc": { "enabled": true, "x": 8.5, "y": 100.0, "z": 0.5, "yaw": 90.0, "name": "&d小游戏服", "skin": "auto" }
}
```

把这条加进 `servers` 数组后**重启**，会自动创建独立存档 `hubsuite_minigame/` 与维度
`hubsuite:server_minigame`，并出现在 `/hub list` 与 `/menu` 里。**不需要改 Java 代码。**

## `fishing` — 海岛渔获（v0.4.0）

按**维度 key** 挂渔获表；没配的维度（生存 / 创造 / 大厅）完全走原版。

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关 |
| `announceRare` | bool | `true` | 钓到 rare / legendary 时给玩家一条提示 |
| `tables` | object | 只有 `hubsuite:skyblock_ocean` | 维度 key → 渔获表 |

一张表 = `displayName` + `replaceVanilla`（true = 完全替换原版）+ `pools`。
每个池子有 `id`、`weight`、`entries`；条目字段：

| 字段 | 含义 |
|---|---|
| `item` | 物品 id，例如 `minecraft:nautilus_shell` |
| `weight` | 池内权重 |
| `amount` | 数量，支持 `"1"` 与 `"1-3"` |
| `rarity` | `common` / `uncommon` / `rare` / `legendary`（幸运值只加稀有以上的权重） |
| `biomes` | 只在这些群系出现（path，不带命名空间）；留空 = 任何群系 |

> 默认表有 **5 个池**：`small_fish` / `big_catch` / `treasure` / `deep_rare` / `junk`，
> 共 40+ 条渔获；幸运值（海之眷顾）只提升稀有以上条目的权重。
>
> "垃圾池"是按群系分的：暖海钓**沙子**、冷水洋钓**砂砾**、冻洋钓**冰块**，
> 冻洋还会出**浮冰**；热带鱼只在暖海出没。

### `fishing.bait` — 副手钓饵加速（v0.4.0-alpha.2）

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `baitSpeedup` | double | `0.10` | 普通钓饵：等待时间 ×(1-值) |
| `compressedSpeedup` | double | `0.25` | 压缩钓饵 |
| `doubleCompressedSpeedup` | double | `0.45` | 二重压缩钓饵 |
| `familyMismatchPenalty` | double | `0.40` | **用错环境**的惩罚：速度 ×(1-值)（0.40 = 打 6 折、等待 ×1.67） |

规则（语义写死）：普通钓饵只在**水里**生效、地狱钓饵只在**岩浆里**生效；
**钓上来一条才扣一个**（放在副手）。

- **渔桶可以混装**不同钓饵，消耗顺序按档次：**二重压缩 → 压缩 → 普通**。
- **散饵用错环境不是"没效果"**：拿普通饵去岩浆里钓 → 按上面的惩罚**减速**，
  压缩不压缩一个价，而且**照样扣一个**。
- **渔桶里只有错误那一族的饵时完全不生效**：不减速、也不扣（桶护饵）。

### 岩浆渔获表（v0.4.0-alpha.2）

默认还挂了两张**岩浆表**：`hubsuite:skyblock_ocean_nether` 与
`hubsuite:skyblock_classic_nether`（用熔岩钓竿在岩浆里钓）。
条目用 `biomes` 按**下界群系**分化：`soul_sand_valley` 出灵魂沙/灵魂土/下界疣、
`crimson_forest` 与 `warped_forest` 出菌类、`basalt_deltas` 出黑石/玄武岩。

### 自定义物品（v0.4.0-alpha.2）

8 个物品，id 都在 `hubsuite:` 下：`nether_string`、`bait`、`nether_bait`、
`compressed_bait`、`compressed_nether_bait`、`double_compressed_bait`、
`double_compressed_nether_bait`、`lava_rod`。
它们是服务端真物品；客户端侧由 **Polymer**（硬依赖）映射成原版物品，
**外观**需要可选资源包（`assets/hubsuite/models/item/<id>.json` + `lang/`）。

## `structureFoundations` — 悬空结构的底座（v0.4.0-alpha.1）

空岛式的下界是纯虚空，原版生成的猪灵堡垒会整片悬空；自然岛上的村庄房屋也可能探出岛外。
这份名单里的结构**一旦生成/放置，就会在它下面垫一层方块**（事件驱动，只在本模组托管的维度生效）。

| 字段 | 类型 | 默认 | 含义 |
|---|---|---|---|
| `structureFoundations` | array | `["minecraft:bastion_remnant"]` | 需要补底座的结构 id（要塞 `minecraft:stronghold` 按需求**不在**名单里） |
| `structureFoundationBlock` | string | `minecraft:netherrack` | 底座方块 |
| `structureFoundationDepth` | int | `4` | 往下垫几层（1..16） |
| `structureFoundationMargin` | int | `1` | 比结构轮廓往外扩几格（0..8） |
