# 自定义物品

> 本模组（v0.4.0 起）的自定义物品全部走 **Polymer**：服务端是真正独立的物品 id
> （配方 / 统计 / NBT 都正常），原版客户端看到的是"试炼钥匙 + 资源包模型"。
>
> - 服务器**必须**装 Polymer（硬依赖）；
> - 外观**必须**靠资源包（见文末"资源包"一节），不装包会显示成缺失模型；
> - 客户端 JEI 的配方页里能看到这些配方，但物品列表里不会出现独立条目。

## 渔桶用法（和原版收纳袋一样）

- **装**：背包里把钓饵"点"到桶上（或拿着桶点钓饵）—— 左键全装、右键装一个；
- **取**：空手右键点桶（或拿着桶右键空格子）—— 取出一组；
- **可以混装**：6 种饵都能进同一只桶，容量按**总个数**算，按"个"计数；
- **钓鱼生效**：桶放副手即可；**消耗顺序按档次 二重压缩 → 压缩 → 普通**
  （先扣最高档的），加速按**这次会扣的那种**算；
- tooltip 会显示"内容物 总数 / 容量" + 最多 3 种明细；
- **模型**按桶里**最高档**的那种饵切换（混装时取最高的那档）。

## 用错环境的惩罚（v0.4.0-alpha.6）

钓饵只对**自己那一族**的环境有效：普通族（钓饵 / 压缩 / 二重压缩）在水里，
地狱族在岩浆里。

- 拿**普通饵去岩浆里**钓（或拿地狱饵下水）：**速度 ×(1 - `familyMismatchPenalty`)**
  （默认 0.40 → 速度打 6 折、等待时间 ×1.67）—— 压缩不压缩**一个价**；
- **副手放散饵**：减速**而且照样扣 1 个**；
- **副手放渔桶、桶里只有错误那一族的饵**：**完全不生效** —— 不减速、也不扣饵（桶护饵）。

## 资源包

pack.mcmeta 用 pack_format 84。每个物品三个文件（以木渔桶为例）：

    assets/hubsuite/items/wooden_fishing_bucket.json
        → { "model": { "type": "minecraft:model", "model": "hubsuite:item/wooden_fishing_bucket" } }
    assets/hubsuite/models/item/wooden_fishing_bucket.json
        → { "parent": "minecraft:item/generated", "textures": { "layer0": "hubsuite:item/wooden_fishing_bucket" } }
    assets/hubsuite/textures/item/wooden_fishing_bucket.png   （16×16）

- **熔岩钓竿**要多一个甩竿状态：items/lava_rod.json 用 minecraft:condition +
  minecraft:fishing_rod/cast 在 hubsuite:item/lava_rod 与 hubsuite:item/lava_rod_cast
  之间切换，两张贴图，模型的 parent 用 minecraft:item/handheld_rod。
- 中文名放在 assets/hubsuite/lang/zh_cn.json，键名即 item.hubsuite.<id>（共 11 条）。

### 渔桶的模型（只看"空 / 有饵"，不分饵的种类）

渔桶只有 **2 个**模型 id：空桶用 hubsuite:<桶>，**只要装了饵**（不管哪种、混装也一样）
都用 hubsuite:<桶>_bait。以木渔桶为例：

| 状态 | 模型 id |
|---|---|
| 空 | hubsuite:wooden_fishing_bucket |
| 装了饵（任何饵、混装都算） | hubsuite:wooden_fishing_bucket_bait |

铁 / 钻石桶同理（前缀换成 iron_ / diamond_）。三只桶一共 6 个模型。
仓库根目录的 HubSuite-资源包模板.zip 已经把全部模型 JSON（11 个物品 + 3 个渔桶状态）
+ 中文名 + 占位贴图打好了，解压改贴图即可用。
