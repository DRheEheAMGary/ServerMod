# HubSuite 命令与权限

所有命令都同时支持控制台执行（涉及玩家的命令会提示"只能由玩家执行"）。

---

## 玩家命令（权限等级 0）

| 命令 | 说明 |
|---|---|
| `/hub` | 返回大厅 |
| `/hub <子服id>` | 进入指定子服，例：`/hub survival` |
| `/hub list` | 列出所有子服与当前在线人数 |
| `/hub where` | 显示自己当前所在场所与登录状态 |
| `/hub login` | 打开登录对话框 |
| `/hub register` | 打开注册对话框 |
| `/login <密码>` | 聊天命令兜底登录 |
| `/register <密码> <确认密码>` | 聊天命令兜底注册 |

> **为什么有聊天兜底命令**：万一客户端没弹出对话框（例如装了会屏蔽自定义界面的模组），
> 密码仍有一条可用通道。代价是密码会进入该玩家的聊天记录 ——
> **优先用对话框**，命令只是后备。

### 大厅交互（不用打命令）

| 操作 | 效果 |
|---|---|
| **右键**大厅假人 | 弹出确认框，显示该服的在线人数、世界类型、模式、难度、PvP、飞行 |
| **左键**大厅假人 | 直接进入该子服 |

## 空岛命令（`/island`，需在空岛服内）

| 命令 | 说明 |
|---|---|
| `/island` | 回自己的岛（没有就创建） |
| `/island create [类型]` | 创建一座岛，类型见 `/island types` |
| `/island home` | 回自己的岛 |
| `/island reset` | 重置自己的岛（地形重新生成，归属不变） |
| `/island delete` | 删除自己的岛（归属清除，地形保留） |
| `/island info` | 查看方格坐标、中心位置、岛型、成员 |
| `/island types` | 列出所有可用岛型 |
| `/island invite <玩家>` | 把某人加为岛员（可以一起建造） |
| `/island visit <玩家>` | 访问别人的岛（未经邀请不能建造） |
| `/island admin reload` | 保存空岛归属数据 |
| `/island admin delete <玩家>` | 删除某人的岛（玩家须在线） |

内置岛型：`classic`（经典空岛）、`ocean`（海岛）。

## 管理命令（权限等级 2 / Game Master）

| 命令 | 说明 |
|---|---|
| `/hub info` | 打印运行状态：各子服的维度、存档路径、规则、集成状态、账号数 |
| `/hub save` | 立即保存所有子服与大厅（含 gamerule 落盘） |
| `/hub reload` | 重新读取配置文件（世界的增删需重启） |
| `/hub selftest` | 跑 49 项内置自检，验证隔离与集成是否成立 |
| `/hub placeholders` | 列出所有可用占位符与集成状态 |
| `/hub perms` | 查看自己当前的权限节点判定结果（排查 LuckPerms 是否接通） |

### 账号管理

| 命令 | 说明 |
|---|---|
| `/hub auth list` | 显示已注册账号数与存储位置 |
| `/hub auth reset <玩家> <新密码>` | 重置密码并解锁账号 |
| `/hub auth delete <玩家>` | 删除账号 |
| `/hub auth kick <玩家>` | 让在线玩家重新登录（作废其会话） |

## 权限节点

本模组的权限判定是**三级降级**的：

```
LuckPerms（经 fabric-permissions-api）  →  原版 OP 权限等级  →  放行
```

| 节点 | 作用 | 未装权限 API 时的回退 |
|---|---|---|
| `hubsuite.admin` | 全部管理命令 | 权限等级 ≥ 2 |
| `hubsuite.build.creative` | 允许在原版作弊指令被屏蔽的子服里使用它们 | 权限等级 ≥ 2 |
| `hubsuite.island.admin` | 空岛管理命令 | 权限等级 ≥ 2 |

### LuckPerms 用法示例

```bash
# 让某组可以管理 HubSuite
lp group admin permission set hubsuite.admin true

# 让某组在创造服可以用 /give 等指令
lp group builder permission set hubsuite.build.creative true
```

用 `/hub perms` 可以直接看到自己这三个节点的判定结果，用来确认 LuckPerms 是否接通。

## 被屏蔽的原版作弊指令

在**创造服这一类子服**里，普通玩家（没有 `hubsuite.build.creative`、也不是 OP）执行
下面这些指令会被拦下并提示：

```
give setblock fill clone summon gamemode effect enchant xp experience item loot
place data attribute damage tag particle playsound stopsound worldborder time
weather difficulty forceload spectate ride transfer spreadplayers random jigsaw
structure publish debug raid bossbar kill butcher seed save-all save-off save-on
```

这是需求里明确要求的"禁止普通玩家用 `/give` 等原版作弊指令，只保留 mod 提供的面板"。

> 想放行某个子服：给对应玩家/组 `hubsuite.build.creative` 节点，或把该玩家设为 OP。
> 想让**所有**子服都放行：删除 `feature/CommandGuard.java` 里的
> `CREATIVE_BLOCKED` 条目（需要改代码重编译）。

## HuskHomes 指令

装了 HuskHomes（Fabric 26.1.2 版）后，这些指令由**它**提供，本模组不重复实现：

```
/sethome /home /delhome /homes /phome
/spawn /setspawn
/tpa /tpahere /tpaccept /tpdeny /tpatoggle
/warp /warps /setwarp /delwarp
/back /rtp
```

**子服开关**：每个子服可以单独关闭这些指令（`servers[].huskhomesTeleport = false`）。
空岛服与创造服默认**关闭** —— 否则玩家用 `/home` 就能把自己传出保护范围。
被拦下时会提示改用 `/hub` 返回大厅。

## 未登录玩家能做什么

未登录状态下：

| 允许 | 禁止 |
|---|---|
| `/login`、`/register`、`/hub`、`/help` | 其它所有命令 |
| 对话框交互 | 移动（每 tick 被拉回）、破坏/放置方块、右键交互、攻击、使用物品 |
| —— | 受到任何伤害、掉落物品 |

超时（默认 120 秒）未完成认证会被踢出。
