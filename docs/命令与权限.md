# 命令与权限

---

## 1. 全部命令

### 玩家命令

| 语法 | 作用 | 权限 |
|---|---|---|
| `/menu` | 打开服务器选择界面（箱子 GUI，与大厅假人同一个界面） | 所有人 |
| `/hub` | 回大厅 | 所有人 |
| `/hub <子服>` | 直达某个子服，如 `/hub survival` | 所有人 |
| `/hub list` | 列出所有子服与在线人数 | 所有人 |
| `/hub where` | 我现在在哪个维度、坐标多少 | 所有人 |
| `/login <密码>` | 认证兜底登录 | 所有人 |
| `/register <密码> <确认密码>` | 认证兜底注册 | 所有人 |

### 空岛命令（需在空岛服相关维度）

| 语法 | 作用 |
|---|---|
| `/island`、`/island help` | 帮助 |
| `/island menu` | 打开选岛界面 |
| `/island hub` | 回空岛服大厅 |
| `/island classic` | 去经典空岛（没有就建一座） |
| `/island ocean` | 去海岛（没有就建一座） |
| `/island home` | 回上次那种岛 |
| `/island info` | 我的岛信息（两种岛型都列出） |
| `/island types` | 列出所有岛型与对应维度 |
| `/island reset [类型]` | 重置我的岛（清归属重建，**谨慎**） |

一个人可以**同时拥有**经典空岛与海岛，归属与地形完全独立。

### 管理命令

| 语法 | 作用 |
|---|---|
| `/hub selftest` | 运行 210 项内置自检（回归测试入口） |
| `/auth list` | 已注册账号数 |
| `/auth reset <玩家> <新密码>` | 重置密码并自动解锁 |
| `/auth delete <玩家>` | 删除账号 |
| `/auth kick <玩家>` | 让某玩家重新登录（作废会话） |

> ⚠️ 这几个命令（含 `/hub selftest`）判定的是**原版 OP 权限等级 2**（Game Master），
> **不走 `hubsuite.admin` 节点** —— 装了 LuckPerms 也只认 OP 等级。控制台执行不受限。

## 2. 大厅交互（不必打命令）

- **右键**大厅假人：弹出确认框，显示该服在线人数、世界类型、模式、难度、PvP、飞行。
- **左键**大厅假人：直接进入该子服。

---

## 3. 未登录玩家的行为

**允许**：`/login`、`/register`、`/hub`、`/help`，以及对话框交互。

**禁止**：其它所有命令；移动（每 tick 拉回）、破坏 / 放置方块、右键交互、攻击、使用物品；
受到任何伤害、掉落物品。

超时（默认 120 秒）未完成认证会被踢出。

> 兜底命令的代价：密码会进入该玩家聊天记录。**优先用对话框。**

---

## 4. 权限节点

判定**三级降级**：

```text
1. LuckPerms（经 fabric-permissions-api 反射桥接）
2. 原版 OP 权限等级
3. 默认放行（控制台 / 无玩家场景）
```

| 节点 | 无权限 API 时的回退 | 作用 |
|---|---|---|
| `hubsuite.admin` | OP 等级 >= 2 | 全部管理命令 |
| `hubsuite.build.creative` | OP 等级 >= 2 | 允许在被屏蔽作弊指令的子服里使用它们 |
| `hubsuite.island.admin` | OP 等级 >= 2 | 空岛管理（预留，当前无对应指令） |

未装权限 API 时整体回落到原版 OP。启动日志会打印当前后端：
`LuckPerms（经 fabric-permissions-api）` / `fabric-permissions-api` / `原版 OP 权限等级`。

原版等级映射：1 = Moderator，2 = Game Master，3 = Admin，4 = Owner。

## 5. LuckPerms 配置示例

```text
/lp user 某人 permission set hubsuite.admin true
/lp creategroup owner
/lp group owner permission set hubsuite.admin true
/lp group owner permission set hubsuite.build.creative true
/lp user 某人 parent add owner
/lp group default permission set hubsuite.admin false
```

> LuckPerms 改完权限后让玩家**重连**（部分缓存要重连刷新）。
> 后端起不来时，先确认 `fabric-permissions-api` 和 `LuckPerms-Fabric` 都在 `mods/` 里。

## 6. 被屏蔽的原版作弊指令

在需要限制的创造性子服里，普通玩家会被拦下这些指令：

```text
give setblock fill clone summon gamemode effect enchant xp experience item loot place
data attribute damage tag particle playsound stopsound worldborder time weather difficulty
forceload spectate ride transfer spreadplayers random jigsaw structure publish debug raid
bossbar kill butcher seed save-all save-off save-on
```

放行方式（优先级从高到低）：

1. LuckPerms 给 `hubsuite.build.creative`；
2. 给玩家 OP（等级 >= 2）；
3. 改 `config.json` 里该子服的 `behaviour` / `allowGameModeCommand` 等开关。

> ⚠️ **这不是可靠的安全边界**：闸门只取命令的第一个词，
> `/execute run give @s diamond 64`、`/function ...` 这类包装可以绕过。别拿它当防作弊。

## 7. 与 HuskHomes 的关系

HuskHomes 提供 `/sethome`、`/home`、`/spawn`、`/tpa`、`/warp`、`/back`、`/rtp` 等指令，
本模组不重复实现。

- **家（`/home`）按子服真正分开**：存储时给家名加子服前缀
  （生存 `1_`、创造 `2_`、空岛 `3_`、大厅 `0_`，见 `integration/HomeNamespace`），
  所以**同名家在不同子服可以各自存在、互不覆盖**。
  玩家输入和 `/homes` 列表仍显示原名 —— 命令层自动改写，列表显示时去掉前缀。
- `servers[].huskhomesTeleport = false` 可单独关掉某个子服的**全部** HuskHomes 传送
  （默认全开）；关掉后在该子服里 `/home` `/tpa` 等会被拦，提示改用 `/hub` 返回大厅。
- HuskHomes 自己的 `huskhomes.*` 权限节点照常工作。

---

## 8. 排查权限问题

1. 看启动日志里打印的**权限后端**；
2. 确认 `fabric-permissions-api` 与 `LuckPerms-Fabric` 都在 `mods/`；
3. 让玩家重连后再试；
4. 记住 `/hub selftest`、`/auth` 只认**原版 OP 等级 2** —— 用控制台 `op <名字>` 最直接。
