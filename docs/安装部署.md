# 安装部署

面向服主：把 HubSuite 装到一个 Fabric 服务端上，跑起来，并知道怎么备份、迁移、重置。

---

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Minecraft | **26.1.2**（严格锁定） |
| 服务端 | **Fabric dedicated server**（不支持 Paper / Spigot / Forge / NeoForge） |
| Fabric Loader | 0.19.5+ |
| Fabric API | 0.155.3+26.1.2 |
| Java | **25** |
| 客户端 | 原版即可，**不需要**装模组 |

> ⚠️ 26.1 起 Minecraft 官方不再混淆代码，Fabric 取消了 Yarn / Intermediary。
> **1.21.11 及更早版本的模组在 26.1.2 上无法加载**。

---

## 2. 依赖 jar 清单

全部放进服务端 `mods/`：

| 文件名 | 必需 | 用途 |
|---|---|---|
| `hubsuite-0.4.0-alpha.1.jar` | 必需 | 本模组 |
| `fabric-api-0.155.3+26.1.2.jar` | 必需 | Fabric API |
| `HuskHomes-Fabric-4.11+mc.26.1.2.jar` | 强烈建议 | 家 / 传送点 / Tpa / Warp 指令 |
| `placeholder-api-3.0.0+26.1.jar` | 建议 | 让其它模组读到 `%hubsuite_...%` |
| `fabric-permissions-api-0.7.0.jar` | 建议 | 权限 API（LuckPerms 的前置） |
| `LuckPerms-Fabric-5.5.85.jar` | 可选 | 权限组管理 |

- **最小可用组合**：`hubsuite` + `fabric-api`。
- 其余为**软依赖**：缺失不会导致启动失败，只在启动日志里提示「未检测到 xxx」。

> 🔴 **HuskHomes 必须是 Fabric 版、版本号带 `26.1.2`**。
> 旧版（如 4.6）编译于 1.20.4、用已废弃的 intermediary 名，在 26.1.2 上会直接加载失败，
> 而且它的版本检查拦不住这个问题。

## 3. 首次启动

启动一次服务端，会自动生成：

**`config/hubsuite/`（全局配置）**

| 文件 | 内容 |
|---|---|
| `config.json` | 主配置（首次写入默认三服：survival / creative / skyblock） |
| `accounts.db` | 账号库（SQLite） |
| `last-locations.json` | 各子服「上次位置」记忆 |
| `rules/` | 各子服 gamerule 快照 |
| `skyblock/islands.json` | 空岛归属 |

**服务端根目录（与主世界 `world/` 平级）**

```text
hubsuite_lobby/      大厅
hubsuite_survival/   生存服
hubsuite_creative/   创造服
hubsuite_skyblock/   空岛服（内部含 hub / classic / ocean 三个维度）
```

每个子服是一个**完整独立存档**：地形、背包、经验、成就、统计、规则都互不影响。

成功日志形如：

```text
[HubSuite] 多世界引擎就绪：大厅 1 个，子服 3 个，耗时 107 ms。
```

### server.properties 建议

```properties
online-mode=false
gamemode=adventure
allow-flight=true
spawn-protection=0
```

> ⚠️ `server.properties` **不能包含任何非 ASCII 字符**（Java Properties 按 ISO-8859-1 读取，
> 中文注释会导致 `MalformedInputException` 启动失败）。

## 4. 验证安装（无需客户端）

控制台执行：

```text
hub selftest
```

跑 **216 项**内置自检，全通过会打印：

```text
通过 216 项，失败 0 项。
```

覆盖范围：存档隔离、规则隔离、玩家数据隔离（落盘位置 + 跨服往返）、成就 / 统计隔离、
账号安全（注册 / 登录 / 锁定 / 重置）、空岛生成 / 保护 / 入口分流、任务逻辑、指令注册、集成适配。

---

## 5. 备份与迁移

```bash
# 备份某个子服（停服后）
tar czf survival-backup.tar.gz hubsuite_survival/
# 建议连同全局配置一起备份
tar czf config-backup.tar.gz config/hubsuite/
```

迁移到新机器：把服务端根目录下的 `hubsuite_*` 存档目录 + `config/hubsuite/` 一起拷过去即可，
没有绝对路径依赖。

---

## 6. 重置

| 想重置什么 | 做法 |
|---|---|
| 某个子服（世界 + 该服玩家数据） | 停服后删除对应目录（如 `hubsuite_creative/`），下次启动自动重建为全新世界；账号不受影响 |
| 空岛归属 | 删除 `config/hubsuite/skyblock/islands.json`（地形方块仍在世界，可用 `/island classic` 重新分配） |
| 全部 | 停服后删 `hubsuite_*` + `config/hubsuite/`（**记得连地图一起删**，见下） |

> **清数据 = 连地图一起清**。只清玩家数据而留着地图，会让旧地形和新地形叠在一起 ——
> 实测出现过「箱子被挤爆」「岛中间有旧树干」。
>
> 强杀服务端后要删掉 `session.lock`，否则下次启动报存档被锁。

## 7. 常见问题

**进服被锁在大厅等待区、动不了？**
未登录玩家会被锁定。填写弹出的注册 / 登录对话框即可。

**对话框没弹出来？**
用 `/register <密码> <确认密码>` 或 `/login <密码>` 兜底（代价：密码会进入该玩家聊天记录，优先用对话框）。

**控制台报「未检测到 HuskHomes」？**
`/sethome`、`/home`、`/spawn`、`/tpa` 等指令不可用，其余功能正常。检查 `mods/` 里的 HuskHomes 版本。

**换服后背包变了？**
设计行为。每个子服的背包 / 经验 / 成就独立，大厅不携带物品。

**点大厅假人没反应？**
看日志两行：

- 有 `切服请求：<玩家> -> <子服>` 但没有 `切服完成` → 传送抛异常，看 `传送 <玩家> 到 <子服> 失败` 的堆栈；
- 两行都没有 → 请求没到服务端。

**第一次进某个子服会卡几秒？**
首次进入需要现生成地形，属正常现象，之后很快（区块已落盘）。

**大厅是永昼晴天？**
是设计（`LobbyEnvironment` 强制永昼 + 晴朗）。

## 8. 升级注意

- 升级 Minecraft / Fabric 版本前，先读 [架构与扩展](架构与扩展.md) 的「Mixin 清单」；
  隔离相关的 Mixin 一旦目标方法签名变化就会失效。
- 旧版本用全局 `world/players/stats/`、`world/players/advancements/` 的存档**不会自动迁移**；
  升级后玩家首次进各子服时成就与统计从空白开始，每个子服各记一份。
  要保留旧进度，可手工把 `world/players/stats/<uuid>.json` 复制到对应子服的 `players/data/stats/` 下。
