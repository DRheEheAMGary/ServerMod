# HubSuite 安装部署

> 适用于 Minecraft **26.1.2** + Fabric Loader 0.19.5+ + **Java 25**
> 纯服务端模组 —— 客户端用原版即可进服，**不需要**安装任何东西。

---

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Minecraft | **26.1.2**（严格锁定，其它版本不保证可用） |
| Fabric Loader | **0.19.5** 或更高 |
| Java | **25**（26.1 起 Mojang 要求 Java 25） |
| 服务端类型 | Fabric dedicated server（不支持 Paper/Spigot/Forge/NeoForge） |
| 客户端 | 原版即可，无需安装模组 |

> ⚠️ **26.1 是一个分水岭**：从 26.1 开始 Minecraft 官方不再混淆代码，
> Fabric 也随之取消了 Yarn/Intermediary 中间名映射。
> 因此 **1.21.11 及更早版本的所有模组在 26.1.2 上都无法加载**，
> 必须使用明确标注支持 26.x 的版本。

---

## 2. 需要放进 mods/ 的文件

把下面 5 个 jar 全部放进服务端的 `mods/` 目录：

| 文件名 | 必需 | 作用 |
|---|---|---|
| `hubsuite-0.1.0.jar` | ✅ **必需** | 本模组 |
| `fabric-api-0.155.3+26.1.2.jar` | ✅ **必需** | Fabric API |
| `HuskHomes-Fabric-4.11+mc.26.1.2.jar` | ⬜ 强烈建议 | 家 / 传送点 / Tpa / Warp 指令 |
| `placeholder-api-3.0.0+26.1.jar` | ⬜ 建议 | Text Placeholder API，让其它模组能读到 `%hubsuite_...%` |
| `fabric-permissions-api-0.7.0.jar` | ⬜ 建议 | 权限 API，LuckPerms 的前置 |
| `LuckPerms-Fabric-5.5.85.jar` | ⬜ 可选 | 权限组管理（创造服管理员授权用得到） |

**最小可用组合**：`hubsuite` + `fabric-api`。
其余都是软依赖，缺了不会导致启动失败，只会在启动日志里给出提示。

> ⚠️ **特别注意 HuskHomes 版本**：必须是 **Fabric 版**且版本号里带 **26.1.2**
> （例如 `HuskHomes-Fabric-4.11+mc.26.1.2.jar`）。
> 老版本（如 4.6）编译于 1.20.4、使用已废弃的 intermediary 混淆名，
> 在 26.1.2 上**必然加载失败**（`NoClassDefFoundError`），且不会被版本检查拦住。

## 3. 首次启动

1. 启动一次服务端，会自动生成：
   ```
   config/hubsuite/config.json          ← 主配置（首次启动写入默认三服配置）
   config/hubsuite/rules/               ← 各子服的 gamerule 快照
   config/hubsuite/accounts.db          ← 账号库（SQLite）
   config/hubsuite/last-locations.json  ← 各子服的"上次位置"记忆
   config/hubsuite/skyblock/islands.json← 空岛归属
   ```
2. 同时会创建 4 个独立存档目录（与主世界 `world/` 平级）：
   ```
   hubsuite_lobby/       ← 大厅
   hubsuite_survival/    ← 生存服
   hubsuite_creative/    ← 创造服
   hubsuite_skyblock/    ← 空岛服
   ```
3. 看到这行日志就说明装好了：
   ```
   [HubSuite] 多世界引擎就绪：大厅 1 个，子服 3 个，耗时 107 ms。
   ```

### 服务端配置建议（`server.properties`）

```properties
online-mode=false          # 离线服（本模组对正版/离线一视同仁，都要注册登录）
gamemode=adventure         # 新玩家默认模式；进大厅后会被强制为冒险
allow-flight=true          # 方便创造服/大厅
spawn-protection=0         # 保护交给各子服的世界边界与空岛方格
```

> ⚠️ `server.properties` **不能出现中文或任何非 ASCII 字符** ——
> Java 的 Properties 按 ISO-8859-1 读取，中文注释会导致服务端启动失败
> （`MalformedInputException`）。

## 4. 验证安装（无需客户端）

控制台执行：

```
hub selftest
```

会跑 49 项内置自检，覆盖：

- 存档隔离（4 个目录两两不同、各有 `level.dat`）
- 规则隔离（各子服持有独立 `GameRules`，PVP/KEEP_INVENTORY 值正确）
- 账号系统（SQLite、PBKDF2 加盐、错误密码拒绝、会话绑定 IP、失败锁定、管理员重置）
- 空岛系统（方格分配、classic/ocean 岛型、地形生成、保护逻辑）
- 集成适配（HuskHomes 版本、占位符注册数量、权限后端）
- **玩家数据隔离**（真实入服路径 → 数据落盘位置正确 → 没有写进主世界存档）

全部通过会打印 `通过 49 项，失败 0 项。`

其它常用诊断命令：

```
hub info          查看各子服的维度、存档路径、规则、集成状态
hub placeholders  列出所有可用占位符
hub perms         查看自己当前的权限节点判定结果
```

## 5. 运维要点

### 备份
每个子服是**一个完整独立的存档目录**，直接打包对应目录即可：

```bash
tar czf survival-backup.tar.gz hubsuite_survival/
```

账号库与空岛归属在 `config/hubsuite/` 下，建议一并备份。

### 重置某个子服
停服后删除对应目录（例如 `hubsuite_creative/`），下次启动会自动重建为全新世界。
归属会重新开始，但**账号不受影响**。

### 重置空岛
删除 `config/hubsuite/skyblock/islands.json` 即可清空所有岛屿归属
（地形方块会留在世界里，可用 `/island create` 重新分配）。

### 迁移
把 `hubsuite_*` 目录 + `config/hubsuite/` 一起拷到新机器即可，
路径无绝对依赖。

## 6. 常见问题

**Q：玩家进服后动不了、只弹出一个对话框？**
正常行为 —— 未登录玩家会被锁在大厅等待区。填完注册/登录表单即可。
如果对话框没弹出来，可以用聊天命令兜底：`/register <密码> <确认密码>` 或 `/login <密码>`。

**Q：控制台报 "未检测到 HuskHomes"？**
`/sethome /home /spawn /tpa` 这些指令会不可用（其它功能正常）。
把 HuskHomes 的 Fabric 26.1.2 版放进 `mods/` 即可。

**Q：玩家说背包在换服后变了？**
这是设计行为 —— 每个子服的背包、经验、成就统计都是**独立**的。
从大厅进子服时背包会被清空（大厅不携带物品）。

**Q：怎么给创造服的管理员开权限？**
三种方式（优先级从高到低）：
1. LuckPerms 给节点 `hubsuite.build.creative`；
2. 给玩家 OP（权限等级 2 及以上）；
3. 修改 `config/hubsuite/config.json` 里对应子服的 `behaviour` 设置。

**Q：点大厅假人进服"没反应"或卡住？**
先看服务端日志有没有这两行：
```
切服请求：<玩家> -> <子服>（清背包=false）
切服完成：<玩家> 现在位于 <子服>（hubsuite:server_xxx，N 人）
```
- **有"切服请求"没有"切服完成"** → 传送过程中抛异常了，日志里会有 `传送 <玩家> 到 <子服> 失败` 加堆栈。
  本项目已修掉最常见的一种：原版 `DistanceManager.removePlayer` 对未登记区块不判空导致的 NPE
  （见 `DistanceManagerRemovePlayerMixin`）。
- **两行都没有** → 请求根本没到服务端，检查客户端是否卡在某个界面上。

首次进入某个子服时，服务端要现生成地形，会卡几秒属于正常；
后续进入该子服会快很多（区块已落盘）。

**Q：大厅一直是白天吗？**
是。大厅强制"永昼 + 晴朗"（`LobbyEnvironment`）。
如果看到夜晚或下雨，说明该功能失效了，把日志发出来。

**Q：想改子服名字/出生点/规则？**
改 `config/hubsuite/config.json` 后重启服务端。世界的增删必须重启才生效，
规则与部分设置可以用 `hub reload` 重新读取。
