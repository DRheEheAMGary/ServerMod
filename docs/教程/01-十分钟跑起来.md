# 01 · 十分钟跑起来

目标：从零到一个能进服、能登录、能切服、自检全绿的服务端。

---

## 1. 编译

需要 **JDK 25**。

```bash
./gradlew build
# 产物：build/libs/hubsuite-0.3.0.jar
```

首次编译会下载依赖（几百 MB），耐心等。

---

## 2. 准备服务端

用 Minecraft **26.1.2** 的 Fabric 服务端。`mods/` 里放：

- `hubsuite-0.3.0.jar`（必需）
- `fabric-api-0.155.3+26.1.2.jar`（必需）
- `HuskHomes-Fabric-4.11+mc.26.1.2.jar`（建议）
- `placeholder-api-3.0.0+26.1.jar`（建议）
- `fabric-permissions-api-0.7.0.jar`（建议）
- `LuckPerms-Fabric-5.5.85.jar`（可选）

> HuskHomes 必须是 4.11+ 的 26.1 构建。

---

## 3. 首次启动

启动一次，会自动生成配置与独立存档：

```text
config/hubsuite/config.json、accounts.db、last-locations.json、rules/、skyblock/
hubsuite_lobby/、hubsuite_survival/、hubsuite_creative/、hubsuite_skyblock/
```

控制台验证：

```text
hub selftest
# => 通过 196 项，失败 0 项。
```

顺手把自己设成 OP：

```text
op 你的名字
```

---

## 4. 进服走一遍

1. 原版客户端直接连（不用装模组）。
2. 弹出**注册对话框**，注册后落到大厅。
3. 点正前方的「点击传送」假人 → 箱子界面列出三个服务器。
4. 点**生存服**进入，随便拿点东西，再 `/hub` 回大厅 —— 背包是空的（大厅不携带物品）。
5. 再 `/hub survival` 回去 —— 东西还在。

---

## 5. 空岛

```text
/island              # 箱子界面：经典空岛 / 海岛 / 任务
/island classic      # 去经典空岛（没有就建一座）
/island ocean        # 去海岛（没有就建一座）
/island hub          # 回空岛服大厅
/island info         # 我的岛信息
/island reset classic
```

一个人可以**同时拥有**经典空岛与海岛。第一次进空岛服会落在空岛大厅（小平台 + 「选择岛屿」假人）。

---

## 6. 常用指令

```text
/menu              服务器选择界面
/hub               回大厅
/hub <服务器>       直达子服
/hub list          服务器列表
/hub where         我在哪
/hub selftest      自检（管理）
/auth list         账号数（管理）
/auth reset <玩家> <新密码>
/auth delete <玩家>
```

---

## 7. 离线服 vs 正版服

两种都支持，**都要注册 + 登录**。

- 离线服（`online-mode=false`）：UUID 由名字推导 —— **换名字 = 换人**。
- 正版服：数据跟随账号。

相关开关在 `config.json` 的 `auth` 段（会话时长、失败锁定、密码长度、PBKDF2 迭代次数）。
