# 01 · 十分钟跑起来

目标：从零到**能进服、能登录、能切服、自检全绿**。

---

## 1. 编译

```bash
./gradlew build
```

产物：`build/libs/hubsuite-0.2.3.jar`

> **首次编译会下载依赖（约几百 MB）**，慢是正常的。
> 需要 JDK 25 —— 26.1 起 Minecraft 用 Java 25，模组也必须匹配。

如果你只想要 jar、不想配环境，直接下载 Release 里的产物即可。

---

## 2. 准备服务端

一个 **Minecraft 26.1.2 的 Fabric 服务端**，`mods/` 里放：

| 文件 | 必需 | 说明 |
|---|---|---|
| `hubsuite-0.2.3.jar` | ✅ | 本模组 |
| `fabric-api-0.155.3+26.1.2.jar` | ✅ | Fabric API |
| `HuskHomes-Fabric-4.11+mc.26.1.2.jar` | 建议 | 家/传送指令 |
| `placeholder-api-3.0.0+26.1.jar` | 建议 | 占位符（Tab/聊天里显示信息） |
| `fabric-permissions-api-0.7.0.jar` | 建议 | 权限后端桥接 |
| `LuckPerms-Fabric-5.5.85.jar` | 可选 | 细粒度权限；**也提供 SQLite 驱动** |

> ⚠️ **HuskHomes 必须用 4.11+ 的 26.1 版本**。
> 4.6 之类的旧版用的是混淆名（`net/minecraft/class_3222`），26.1 已不再混淆，
> 旧版会直接加载失败。

## 3. 启动并放行自己

首次启动会自动生成：

```
config/hubsuite/config.json          主配置
config/hubsuite/accounts.db          账号库（SQLite）
hubsuite_lobby/                      大厅存档
hubsuite_survival/ hubsuite_creative/ hubsuite_skyblock*/
                                     各子服独立存档
```

控制台执行：

```
hub selftest
```

看到 `通过 182 项，失败 0 项` 就说明一切正常。

**给自己 OP**（这样能用管理指令）：

```
op 你的名字
```

---

## 4. 进游戏

客户端**原版即可**，不需要装任何模组。连接后：

1. **弹出注册对话框** —— 填密码注册（这是 26.1 的原版对话框表单）
   - 万一客户端弹不出（装了屏蔽自定义界面的模组），可以用 `/register <密码> <确认>`
2. 注册成功后落到**大厅**，正前方有一个假人，头顶写着 **点击传送**
3. **点假人** → 弹出箱子界面，里面是三个服务器（带图标、在线人数、PvP/飞行状态）
4. 点「生存服」→ 直接进服
5. 在生存服拿点东西，然后 `/hub` 回大厅 → **大厅背包是空的**（物品留在生存服）
6. 再 `/hub survival` → **物品还在**

## 5. 空岛怎么玩

```
/island              →  箱子界面：经典空岛 / 海岛 / 任务
/island classic      →  去经典空岛（没岛就建一座）
/island ocean        →  去海岛（自然海洋世界）
/island hub          →  回空岛服大厅
/island info         →  我的岛信息
/island reset classic →  重置我的经典空岛
```

**一个人可以同时拥有经典空岛和海岛**，两者的归属、地形、背包完全独立。

第一次进空岛服会落到**空岛大厅**（一块小平台 + 一个「选择岛屿」假人），
选了岛型之后才会被送到自己的岛上。

## 6. 常用指令

| 指令 | 用途 |
|---|---|
| `/menu` | 服务器选择界面 |
| `/hub` | 回大厅 |
| `/hub <服务器>` | 直达某个子服 |
| `/hub list` | 列出所有服务器与在线人数 |
| `/hub where` | 我现在在哪、坐标多少 |
| `/hub selftest` | 自检（管理员） |
| `/island` | 岛屿界面 |
| `/auth list` | 已注册账号数（管理员） |
| `/auth reset <玩家> <新密码>` | 重置密码（管理员） |
| `/auth delete <玩家>` | 删号（管理员） |

## 附：离线服 vs 正版服

模组两种都支持，**都要注册登录**（这是需求）。

| | 离线服（`online-mode=false`） | 正版服（`online-mode=true`） |
|---|---|---|
| UUID 来源 | 由名字推导 | 正版账号 |
| 换名字 | 等于换人（数据不跟随） | 数据跟随账号 |
| 建议 | 开启 IP 会话（默认开）减少重复登录 | 可把 `sessionMinutes` 调小 |

配置项在 `config.json` 的 `auth` 段，见 [配置说明](../配置说明.md)。
