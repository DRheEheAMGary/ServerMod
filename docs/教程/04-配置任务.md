# 04 · 配置任务

任务系统在 `config.json` 的 `quests` 段。**全部可在配置里增删改，不用改代码。**

---

## 玩家看到什么

```
/island  →  箱子界面  →  点「空岛任务」
```

任务界面分三类，底部按钮切换：

```
里程碑(14)  |  每日任务(3)  |  物资交付(3)
```

每个条目显示：图标、名称、进度条、目标、奖励。
**点一下就领奖**（交付类会先扣物品）。

---

## 三种类型

| `kind` | 行为 | 能否重复 |
|---|---|---|
| `milestone` | 完成一次，永久打勾 | ❌ 只能领一次 |
| `deliver` | 交物品换奖励 | ✅ 可反复做 |
| `daily` | 每天重置 | ✅ 每天一次 |

---

## 一个任务的完整字段

```json
{
  "id": "stone_64",
  "kind": "milestone",
  "name": "§7石匠入门",
  "description": "挖 64 个石头",
  "icon": "minecraft:stone",
  "goal": "break:minecraft:stone",
  "amount": 64,
  "rewards": ["minecraft:stone_pickaxe*1", "minecraft:bread*4"]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识（小写）。**改了等于换一个新任务**，玩家已完成的记录不会跟过去 |
| `kind` | `milestone` / `deliver` / `daily` |
| `name` | 显示名，支持 `§` 与 `&` 颜色码 |
| `description` | 一句话说明 |
| `icon` | 界面里的图标物品 |
| `goal` | 目标，见下表 |
| `amount` | 需要的数量 |
| `rewards` | 奖励列表，格式 `物品id*数量`（数量可省，默认 1） |

---

## 目标语法（`goal`）

格式是 `类型:参数`：

| 写法 | 含义 | 例子 |
|---|---|---|
| `break:<方块>` | 破坏方块 | `break:minecraft:stone` |
| `place:<方块>` | 放置方块 | `place:minecraft:cobblestone` |
| `kill:<生物>` | 击杀生物 | `kill:minecraft:zombie` |
| `have:<物品>` | **背包里持有**（不消耗，丢掉会退进度） | `have:minecraft:diamond` |
| `deliver:<物品>` | **交付**（会从背包扣除） | `deliver:minecraft:cobblestone` |
| `reach_y:<高度>` | 到达某个 Y 坐标 | `reach_y:120` |
| `enter:<子服>` | 进入某个场所 | `enter:ocean` |

> **`have` 和 `deliver` 的区别很重要**：
> `have` 是"攒够 N 个"，物品还在你手里；
> `deliver` 是"交出去 N 个"，领奖时会被扣掉。
> 想做成"用物资换奖励"就用 `deliver`。

**命名空间可以省略** —— `stone` 等价于 `minecraft:stone`。

---

## 奖励语法

```json
"rewards": [
  "minecraft:diamond*3",
  "minecraft:bread*8",
  "minecraft:diamond_pickaxe"
]
```

- `物品id*数量`，数量省略则为 1
- 数量会被**自动夹到该物品的堆叠上限**（不会出现"一槽 256 个石头"）
- 背包放不下时**掉在脚下**，不会凭空消失
- 认不出的物品会跳过并打警告日志，不会让领奖失败

## 内置的 20 个任务

**里程碑（14）**：第一块木头 → 工作台 → 石匠入门（64 石头）→ 圆石储备（128）
→ 小麦丰收 → 烤面包 → 夜里的东西（10 僵尸）→ 白骨（10 骷髅）
→ 铁器时代（32 铁锭）→ 第一颗钻石 → 钻石储备（16）→ 渔猎（16 鱼）
→ 出海（船）→ 登高（Y=120）

**物资交付（3）**：收石头（64 圆石 → 1 钻石）、收小麦（32 → 4 铁锭）、收木头（64 → 骨粉）

**每日任务（3）**：每日·采矿（128 石头）、每日·清怪（20 怪物）、每日·钓鱼（8 鱼）

这些都可以直接删改。想清空重来就把 `quests.quests` 设成 `[]`，
然后把下面这套内置定义删掉重新写。

---

## 每日任务的重置时机

由 `quests.dailyResetHour` 控制，默认 **4 点**：

```json
"dailyResetHour": 4
```

意思是"凌晨 4 点算新的一天"，而不是自然日 0 点。
这样玩家熬夜到 2 点做的任务不会被"跨天"重置掉。

进度存在 `config/hubsuite/skyblock/quests.json`，按玩家 UUID 分记录。

---

## 注意

**任务进度只在空岛相关维度里累计**（大厅 / 经典空岛 / 海岛）。
在生存服挖石头不会推进空岛任务 —— 这是刻意的，避免刷任务。

**改任务定义后需要重新加载。** 重启服务端最稳；`/hub reload` 只重读配置，
任务管理器是启动时建的，所以**建议重启**。

**不要给同一个 `id` 写两个任务** —— 后面的会覆盖前面的。
