# 04 · 配置任务

目标：会用三类任务、目标语法与奖励，配出自己的任务线。

---

## 1. 入口

`/island` → 箱子界面 → **任务**。界面分「里程碑 / 每日 / 物资交付」，点一下领奖。

进度存在 `config/hubsuite/skyblock/quests.json`，按玩家 UUID 分记录。

---

## 2. 三类任务

| `kind` | 行为 |
|---|---|
| `milestone` | 完成一次**永久打勾**，只能领一次 |
| `deliver` | 交物品换奖励，可反复做 |
| `daily` | 每天重置，每天一次 |

「一天」从 `quests.dailyResetHour`（默认 `4`，即凌晨 4 点）开始算。

---

## 3. 一个任务的完整字段

```json
{
  "id": "stone_64",
  "kind": "milestone",
  "name": "§7石匠入门",
  "description": "挖 64 个石头",
  "icon": "minecraft:stone",
  "goal": "break:minecraft:stone",
  "amount": 64,
  "rewards": ["minecraft:stone_pickaxe*1", "minecraft:bread*4"]
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一（小写）；改了等于换新任务，已完成记录不跟过去 |
| `kind` | 见上 |
| `name` / `description` | 支持 `§` 与 `&` 颜色码 |
| `icon` | 界面图标物品 |
| `goal` | 目标，语法见下 |
| `amount` | 需要完成的数量 |
| `rewards` | 奖励，`物品id*数量` |
| `requires` | 前置任务 id（留空表示无） |

---

## 4. `goal` 语法

格式：`类型:参数`。命名空间可省略（`stone` 等价 `minecraft:stone`）。

| 目标 | 含义 |
|---|---|
| `break:<方块>` | 挖掉该方块 |
| `place:<方块>` | 放下该方块（右键箱子不算） |
| `kill:<生物>` | 击杀该生物 |
| `have:<物品>` | 背包持有（不消耗，丢掉会退进度） |
| `deliver:<物品>` | 交物品（从背包扣除） |
| `reach_y:<高度>` | 到达该高度 |
| `enter:<子服>` | 进入某子服（⚠️ 已定义但**当前不会推进进度**） |

---

## 5. 奖励语法

`物品id*数量`，数量省略为 1。数量会自动夹到物品堆叠上限；背包放不下会掉在脚下；
认不出的物品跳过并打警告。

---

## 6. 注意事项

- **进度只在空岛相关维度累计**（大厅 / 经典空岛 / 海岛）；生存服挖石头不推进（刻意，避免刷任务）。
- 不要给同一个 `id` 写两个任务（后者覆盖前者）。
- 改任务定义后**建议重启**（任务管理器启动时构建，运行期只重读配置对象）。
- 内置一套围绕空岛前期的任务（采矿 / 食物 / 铁 / 钻石 / 每日 / 交付），可直接改或删。
