# 02 · 加一个子服

目标：**纯改配置**新增一个服务器，不写一行 Java。

---

## 1. 加一条配置

打开 `config/hubsuite/config.json`，在 `servers` 数组里加：

```json
{
  "id": "adventure",
  "displayName": "§6冒险服",
  "enabled": true,
  "order": 3,
  "worldKind": "normal",
  "seed": 20260606,
  "useWorldSpawn": true,
  "gameMode": "survival",
  "difficulty": "hard",
  "forceGameMode": true,
  "rememberLastLocation": true,
  "permissionGroup": "hubsuite.adventure"
}
```

字段含义见 [配置说明](../配置说明.md)。

---

## 2. 重启

**必须重启服务端。** 维度只能启动时一次性建立，运行期无法新建。

重启后会自动创建：

```text
hubsuite_adventure/            独立存档
hubsuite:server_adventure      独立维度
```

并出现在 `/hub list`、`/hub adventure`、`/menu` 里；如果配了 `npc`，大厅里会多一个假人。

---

## 3. 核对常用字段

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，也是 `/hub <id>` 与存档目录名；改了等于换新世界 |
| `displayName` | 显示名，支持 `&` / `§` 颜色代码 |
| `worldKind` | `normal` 原版地形 / `flat` 超平坦 / `void` 虚空 |
| `seed` | 世界种子；改了会让出生点缓存失效重算 |
| `useWorldSpawn` | `normal` 建议 `true`；`flat` / `void` 需 `false` + 手填 `spawnX/Y/Z` |
| `gameMode` / `forceGameMode` | 进入时的模式；`forceGameMode` 强制切 |
| `allowGameModeCommand` | 是否允许玩家自己 `/gamemode` |
| `rememberLastLocation` | 再次进入是否回到上次位置 |
| `permissionGroup` | 权限组前缀（接 LuckPerms） |
| `huskhomesTeleport` | 是否允许 HuskHomes 传送指令 |

嵌套段：`behaviour`（本模组规则）、`gameRules`（原版规则）、`flatLayers`（仅 flat）、`npc`。

---

## 4. 踩坑

- **不要在运行中改 `id`**：会新建空世界，旧存档还在磁盘但不再加载（改回去可恢复）。
- **`worldKind` 变了必须删旧存档**：维度类型记在 `level.dat` 里，停服后
  `rm -rf run/hubsuite_adventure` 再启动。
- 加完看启动日志，配置写错会打印「子服 'xxx' 加载失败，已跳过。」。
