# 02 · 加一个子服

**不需要写代码**，往 `config/hubsuite/config.json` 的 `servers` 数组里加一条即可。

---

## 最小例子：加一个「冒险服」

```json
{
  "id": "adventure",
  "displayName": "§6冒险服",
  "enabled": true,
  "order": 3,
  "worldKind": "normal",
  "seed": 0,
  "useWorldSpawn": true,
  "gameMode": "survival",
  "difficulty": "hard",
  "forceGameMode": true,
  "rememberLastLocation": true
}
```

保存后：

```
/hub reload      # 重新读配置（会提示"世界的增删需要重启"）
```

**新增子服必须重启服务端** —— 维度是在启动时一次性建立的，运行时无法卸载/新建。
重启后你会看到：

```
新建独立存档 'hubsuite_adventure'（§6冒险服）
子服 'adventure' 由原版算出出生点：(x, y, z)
子服 'adventure' 使用原版出生点：(x.5, y.0, z.5)
多世界引擎就绪：大厅 1 个，子服 4 个
```

然后 `/hub adventure` 就能进了，`/menu` 里也会**自动多出一项**（界面是从配置动态生成的）。

## 字段说明

### 必填

| 字段 | 说明 |
|---|---|
| `id` | 唯一标识，全小写，会成为 `/hub <id>`。**决定存档目录名**（`hubsuite_<id>`），改了等于换新世界 |
| `displayName` | 显示名，支持 `§` 颜色码 |
| `worldKind` | `normal` 正常地形 / `flat` 超平坦 / `void` 虚空 |

### 常用

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 设为 `false` 可临时下架（存档保留，不加载） |
| `order` | — | 在列表/界面里的排序 |
| `seed` | `0` | 世界种子。**改了会让出生点缓存失效并重算** |
| `useWorldSpawn` | `true` | `true` = 让原版算地表出生点；`false` = 用下面的 `spawnX/Y/Z` |
| `spawnX/Y/Z` | — | `useWorldSpawn=false` 时使用 |
| `gameMode` | `survival` | `survival` / `creative` / `adventure` / `spectator` |
| `forceGameMode` | `true` | 进服强制切模式 |
| `allowGameModeCommand` | `false` | 是否允许玩家自己 `/gamemode` |
| `rememberLastLocation` | `true` | 记住上次位置，再进服时回到原地 |
| `permissionGroup` | — | 该子服的权限节点前缀，例如 `hubsuite.survival` |
| `huskhomesTeleport` | — | 是否允许 HuskHomes 在这个子服传送 |
| `difficulty` | `normal` | `peaceful` / `easy` / `normal` / `hard` |

### 嵌套段

```json
"behaviour": {
  "pvp": false,
  "invulnerable": true,
  "fallDamage": true,
  "explosionBlockDamage": false,
  "fireSpread": false,
  "mobGriefing": false,
  "tntIgnition": false,
  "allowItemDrop": true
},
"gameRules": {
  "KEEP_INVENTORY": "true",
  "SPAWN_MONSTERS": "true",
  "SHOW_DEATH_MESSAGES": "true"
},
"flatLayers": ["minecraft:bedrock*1", "minecraft:grass_block*3"],
"npc": { "enabled": false }
```

- **`behaviour`** 是这个模组自己的规则（比 gamerule 更早生效，且能做到 gamerule 做不到的事，比如"禁止爆炸破坏方块"）
- **`gameRules`** 是**按子服独立**的原版规则 —— 生存服开 `KEEP_INVENTORY`、创造服关，互不影响
- **`flatLayers`** 只在 `worldKind=flat` 时用，格式 `方块id*层数`
- **`npc`** 单个子服的专属假人入口。**默认关闭** —— 现在统一用大厅那个「点击传送」假人开界面，不用为每个子服摆假人

## 独立到什么程度

新子服自动获得：

| | 是否独立 |
|---|---|
| 世界存档（地形/方块/实体） | ✅ 完全独立目录 |
| 玩家背包 / 经验 / 末影箱 / 血量 | ✅ 按维度分开存 |
| **成就 / 统计** | ✅ 按维度分开存 |
| 原版 gamerule | ✅ 独立一份 |
| 世界边界 | ✅ 独立半径 |
| 位置记忆 | ✅ 按 `玩家 × 子服` 分键 |

**全局共享**的有：聊天、Tab 列表（假人不显示）、玩家之间的传送（HuskHomes 按配置）。

---

## 踩坑提醒

**不要在运行中改 `id`。** 它决定存档目录名，改了会"新建一个空世界"，
旧存档还在磁盘上但不会再被加载（想恢复就把 `id` 改回去）。

**`worldKind` 从 `flat` 改成 `normal`（或反过来）必须删掉旧存档。**
维度类型在存档的 `level.dat` 里，不匹配会出错：

```bash
# 停服后
rm -rf run/hubsuite_adventure
```

**加子服后记得看一眼启动日志**。如果配置写错（比如 `worldKind` 拼错），
会看到 `子服 'xxx' 加载失败，已跳过。` —— 后面跟着具体原因。
