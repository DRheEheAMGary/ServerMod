## 最短路径

```text
./gradlew build                        # 产物 build/libs/hubsuite-0.4.0-alpha.1.jar
→ 放进服务端 mods/（连同 Fabric API）
→ 控制台 hub selftest                  # 应输出「通过 216 项，失败 0 项」
→ 进游戏，点大厅「点击传送」假人 / 用 /island / 用 /menu
```

## 遇到问题先做三件事

1. 看**控制台**（日志前缀统一 `(HubSuite)`）；
2. 跑 **`hub selftest`**；
3. 对照 [07 · 排查问题](07-排查问题.md)。
