## 最短路径

```bash
# 1. 编译
./gradlew build                     # 产物 build/libs/hubsuite-0.2.3.jar

# 2. 放进服务端 mods/（连同 Fabric API），启动

# 3. 控制台验证
hub selftest                        # 应输出「通过 182 项，失败 0 项」
```

进游戏后：

```
点大厅里的「点击传送」假人   →  箱子界面选服务器
/island                     →  箱子界面（经典空岛 / 海岛 / 任务）
/menu                       →  服务器选择界面（与假人同一个）
```

## 这个模组做了什么（一句话版）

**一个纯服务端模组**：客户端原版即可进服。

- 进服弹**对话框**注册/登录（密码不进聊天、不进日志）
- 大厅里**假人**点开**箱子界面**选服务器
- 生存 / 创造 / 空岛三个子服，**各有独立存档、独立规则、独立背包与成就**
- 空岛服是**一个子服三个维度**：公共大厅 + 经典空岛（网格）+ 海岛（自然海洋）
- 内置**任务系统**（里程碑 / 物资交付 / 每日）

## 遇到问题先做这三件事

1. **看控制台**。模组的日志前缀统一是 `(HubSuite)`，绝大多数问题它都说清楚了。
2. **跑 `hub selftest`**。182 项检查覆盖存档隔离、规则隔离、数据隔离、
   账号安全、空岛生成、任务逻辑、指令注册 —— 它会直接告诉你哪一环坏了。
3. **对照 [排查问题](07-排查问题.md)**。那里按"现象 → 原因 → 处理"列了已知情况。
