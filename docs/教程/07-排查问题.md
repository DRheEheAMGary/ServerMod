# 07 · 排查问题

按「现象 → 原因 → 处理」组织。先说通用入口。

---

## 0. 先做三件事

```bash
grep "(HubSuite)" run/logs/latest.log | tail -50   # 看日志（前缀统一）
hub selftest                                     # 跑自检
grep -c Watchdog run/logs/latest.log             # 期望 0
```

崩溃栈在 `run/crash-reports/`，搜 `hubsuite` 找**非关服路径**那一帧。

---

## 1. 进不去

| 现象 | 原因 | 处理 |
|---|---|---|
| 连上就被踢「配置时出现意外错误」 | 多半是 Mixin 挂了 | 看 `ClassCastException` / `InvalidMixinException`；典型是 `PrepareSpawnTaskMixin` 匹配错目标 |
| 一直「正在连接」 | 主线程卡住 | 看是否有区块同步加载 / 看门狗 |
| 弹不出注册框 | 客户端屏蔽了自定义界面 | 用 `/register` / `/login` 兜底 |

---

## 2. 登录 / 账号

- 「名字已注册」→ 用 `/login`；忘记密码要管理员 `/auth reset <玩家> <新密码>`。
- 连续失败 5 次锁 10 分钟；`/auth reset` 会自动解锁。
- 改密码后旧会话作废（已修）。

---

## 3. 切服 / 数据

| 现象 | 检查 |
|---|---|
| `/hub` 后进不去别的子服 | 看日志三行：`切服请求：<玩家> -> <子服>` / `切服完成` / `传送 ... 失败` |
| 背包没跟过来 | 设计如此：各子服背包独立，大厅应为空 |
| 玩家数据写到了主世界 | `ls run/world/players/data` 应为空；数据应在 `run/hubsuite_<子服>/players/data/` |
| 成就 / 统计串味 | 2026-10 已修；旧全局文件不自动迁移，可手工 `cp` |

---

## 4. 服务器卡死（最严重）

日志出现：

```text
A single server tick took 60.00 seconds
```

**根因**：在主线程对**未加载区块**做 `getBlockState` / `setBlockAndUpdate` / `getChunk` ——
三者都会同步生成整片区块并原地等待；海洋地形尤其重。

**正确写法**：

```java
if (level.getChunkSource().getChunkNow(cx, cz) == null) {
    // 登记待办，下一 tick 重试
    return;
}
```

> 不要用 `hasChunk` 当守卫：它只保证「非空」，不代表到 FULL。
> 也不要在重维度用 `/forceload`（会同步加载区块）。

---

## 5. 启动慢

首次建世界 + 出生点搜索（最多 121 个区块的螺旋）约几秒；后续用缓存。
新装 / 清档后第一次必然要算一次，属正常。

## 6. 空岛

| 现象 | 处理 |
|---|---|
| 一直往下掉 / 岛没生成 | 地形延迟生成，看日志「区块还没加载，地形稍后补铺」与「已补铺完成」 |
| 提示「不是我的空岛区域」 | 经典按方格、海岛按距离判定 |
| `/island` 说请先进入空岛服 | 2026-10 已修为遍历子服全部维度 |

---

## 7. 任务

- 进度不涨：必须在**空岛相关维度**累计；看日志有没有「推进任务进度失败」。
- 界面空：看启动日志「任务系统已就绪：N 个任务」。
- 改配置没生效：建议重启。

---

## 8. 假人

- 不见了：看日志「大厅引导假人已就绪：N 个」，检查 `config.lobby.menuNpc.enabled`。
- 出现在 Tab：已修（`listed` 硬编码问题）。
- 点假人没反应：假人只对**已认证**玩家响应。

---

## 9. 不是 bug 的情况

**从存档统计群系全是 `plains`？**
区块构造时群系容器先填默认 `plains`，要等生成走到 `BIOMES` 才被真正群系源覆盖。
只统计 `Status` 为 `biomes` 及之后的区块；或问 `level.getNoiseBiome(x>>2, y>>2, z>>2)`
（不碰区块数据、不加载区块）。

**直接 compute 密度函数读到 0？**
原版函数外包了 `flat_cache` / `cache_2d`，缓存要靠 `fillArray` 初始化；
应问 `level.getChunkSource().randomState().sampler()`。
