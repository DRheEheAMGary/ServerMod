## 2. 构建与起服

```bash
./gradlew build                     # 产物 build/libs/
./gradlew runServer                 # 测试服务端（工作目录 run/）
```

无人在场时让服务端起来就自检：

```bash
./gradlew runServer --console=plain '-Dhubsuite.selftest=20'
```

> 端口只能改 `run/server.properties`；`-Pport=` 无效。**不要占 25565。**

## 3. 自检

`hub selftest` 跑 **230 项**，覆盖存档 / 规则 / 玩家数据隔离、账号安全、空岛、任务、指令注册、集成适配。
**改完代码先跑自检**，看 `失败 0 项` 且看门狗 0 次。

加自检的注意事项：整体跑在 `END_SERVER_TICK` 里（同步），不要同步加载区块 / 大范围扫描 / 同步落盘；
要等世界生成用 `defer(...)`；读方块前用 `getChunkNow(...) != null` 确认到 FULL。

---

## 4. 铁律：不要在未加载区块上读 / 写方块

`getBlockState` / `setBlockAndUpdate` / `getChunk` 都会同步生成整片区块，累计被看门狗强杀过四次。

正确做法：先 `getChunkNow(...) != null` 探测；没加载就登记待办，下一 tick 重试
（抄 `IslandManager.generate()` 与 `SubServer` 的待补铺逻辑）。测群系用 `getNoiseBiome`。

---

## 5. 指令必须在初始化阶段注册

`CommandRegistrationCallback` 在服务端启动前就触发完了，放 `SERVER_STARTED` 里注册的指令进不了 dispatcher
（`/island` 一度是死指令）。依赖运行时对象用 `supplier` 延迟解析。

---

## 6. 没有「卸载维度」这回事

`MinecraftServer.levels` 是启动时一次性建立的只读映射；新增 / 删除子服必须重启，
重置地图只能删磁盘存档。也不要在 `SERVER_STOPPING` 提前摘维度（`RegionFile` 句柄会开到 JVM 退出）。

**关服两阶段**：`SERVER_STOPPING` 只主动落盘，`SERVER_STOPPED` 才清路由 / 关存档。
（原来清理全放 STOPPING，导致 `playerList.saveAll()` 把在线玩家最终状态写进主世界，玩家最后一段成果永久丢失。）

---

## 7. 玩家数据是三份，不是一份

`playerIo`（背包/经验/末影箱）+ `stats` + `advancements`。
后两者的路径来自 `MinecraftServer.getWorldPath(...)`，与玩家维度无关；
`ServerStatsCounter` / `PlayerAdvancements` 把路径**烧死在字段里**，切维度时必须从 `PlayerList` 缓存移除并换掉引用。

---

## 8. Mixin 注意事项

1. Mixin 类里**不能有非 private 静态方法** → 用 holder（如 `CommandGuardHolder`）。
2. 普通代码**不能直接引用 mixin 包里的类** → helper 放业务包。
3. `@ModifyExpressionValue` / `@At` 多匹配时**指定 ordinal**（`PrepareSpawnTaskMixin` 不指定会命中第二处）。
4. 改 record 字段：`@Shadow @Final @Mutable`，构造器 `RETURN` 后改。

## 10. 干净验证流程（清档起服）

```bash
pkill -9 -f devlaunchinjector
sleep 5
rm -rf run/hubsuite_* run/world run/config/hubsuite
rm -f run/*/session.lock
./gradlew runServer --console=plain '-Dhubsuite.selftest=20'
```

> 强杀后必须删 `session.lock`，否则下次启动报存档被锁。
> 不要在重维度 `/forceload`。
