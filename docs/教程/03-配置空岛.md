# 03 · 配置空岛

目标：搞懂空岛服的**一个子服、多个维度**，并会调岛型、下界与自然岛。

---

## 1. 结构

```text
hubsuite:skyblock_hub            公共大厅（平台 + 「选择岛屿」假人）
hubsuite:skyblock_classic        经典空岛（网格方格，每人格子一座）
hubsuite:skyblock_ocean          海岛（自然海洋世界，岛按距离摆放）
hubsuite:skyblock_classic_nether 经典空岛的下界（虚空式，落点补下界岩小岛）
hubsuite:skyblock_classic_end    经典空岛的末地（原版）
hubsuite:skyblock_ocean_nether   海岛的下界（岩浆海，液面 Y=96）
hubsuite:skyblock_ocean_end      海岛的末地（原版）
```

每个维度各有**独立存档**，背包 / 成就 / 统计天然互不覆盖。

**入口分流**：进空岛服时，上次在某个岛上 → 直接回那座岛；有岛但人在别处 → 回最近玩的那种岛；
还没岛 → 落大厅，点假人选岛型。

---

## 2. 两种岛型对比

| | 经典空岛（classic） | 海岛（ocean） |
|---|---|---|
| 地形 | 虚空 + 网格方格 | 自然生成的海洋世界 |
| 岛的摆放 | 方格 `plotSize+plotGap` | 按 `oceanSpacing` 距离摆放 |
| 岛形 | 正方形平台 | 不规则圆岛（草地 + 沙滩环 + 水下缓坡） |
| 掉下去 | 传送回自己的岛 | 落海，自己游回 / 传回 |
| 归属文件 | `config/hubsuite/skyblock/islands.json` | 同左 |

---

## 3. 配置 `island` 段

通用：

| 字段 | 默认 | 说明 |
|---|---|---|
| `serverId` | `skyblock` | 挂在哪个子服上 |
| `defaultType` | `classic` | 默认岛型 |
| `autoCreateOnFirstJoin` | `true` | 首次进入自动建岛 |
| `voidY` | `0` | 掉到该高度以下视为掉虚空 |
| `hubNpc` | 见配置说明 | 空岛大厅选岛假人 |

经典空岛：`plotSize`（默认 256，方格边长）、`plotGap`（默认 32）、`islandY`（默认 100）、`islandOffsetX/Z`。

海岛：`oceanSpacing`（默认 320）、`oceanIslandY`（默认 0 = 跟海平面走）。

方格坐标换算：方格 `(0,0)` 中心在世界原点，覆盖 `[-plotSize/2 - gap/2, +plotSize/2 + gap/2)`。
默认 `plotSize=256`、`plotGap=32` 时一格占 **288** 格宽。

## 4. 加一种岛型

```json
{
  "id": "nether",
  "displayName": "&c地狱空岛",
  "description": "&7下界岩小岛，出生就带烈焰粉",
  "layers": ["0:minecraft:netherrack", "-1:minecraft:netherrack", "-2:minecraft:blackstone"],
  "tree": false,
  "chest": true,
  "loot": ["minecraft:blaze_powder*4", "minecraft:flint_and_steel*1", "minecraft:obsidian*10"]
}
```

加完重启，玩家即可 `/island nether`。`layers` 格式 `y偏移:方块id`。

---

## 5. 海洋世界是怎么生成的

`OceanWorldGenerator` 自己写噪声：一条 y 方向斜坡 + 两个尺度的噪声决定海床高度，
海床**恒定落在海平面以下**（约 Y=33~57，水面 Y=62），所以永远不会冒出天然陆地；
群系由同一条 continentalness 曲线驱动温度带与深浅。

## 6. 下界、末地与自然岛（v0.4.0）

- **保护规则已整体删除**：谁都能在空岛服/海岛服任意位置建造（不再有"这不是你的岛屿区域"）。
- 每个岛屿维度都有自己的**下界与末地**，从岛上点火、传送门自动改道到它自己的那一界。
  - 空岛的下界是**虚空式**：出门是一片虚空，但门下面会自动补一座全下界岩的小岛；
    虚空里还会长出**下界要塞与猪灵堡垒**（结构集已放行）。
  - 海岛的下界是**岩浆海**：液面抬到 Y=96，低地全泡在岩浆里。
  - 两座末地都是原版。
- **自然岛**：`naturalIslands` 里每个坐标会铺一座小岛，自带**宝箱**、**刷怪笼**，
  还会放一座**原版村庄房屋**（`naturalIslandHouses`）。位置、半径、物资、生物都能改。

## 7. 常见问题

**一直往下掉 / 岛没生成？**
地形是**延迟生成**的：建岛时玩家还在旧维度，区块必然没加载，强行生成会卡死主线程。
日志会打「方格(x, z) 的区块还没加载，地形稍后补铺」，等玩家落到岛上（区块自然加载）再补铺。

**提示「不是我的空岛区域」？**
确认是哪种岛：经典按**方格**判定、海岛按**离岛距离**判定。

**重置岛？**
`/island reset classic`（或 `ocean`）；彻底重来则停服删 `hubsuite_skyblock_*` 与
`config/hubsuite/skyblock/`，下次启动重建。

**海岛很重？**
首次进入某片区域要现场生成，属正常现象。
