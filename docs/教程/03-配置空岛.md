# 03 · 配置空岛

空岛服是这个模组结构最特别的地方：**一个子服、三个维度**。

```
hubsuite:skyblock_hub      公共大厅（平台 + 「选择岛屿」假人）
hubsuite:skyblock_classic  经典空岛（网格方格，每人格子一座）
hubsuite:skyblock_ocean    海岛（自然生成的海洋世界，岛按距离摆放）
```

三个维度**各有独立存档**，所以玩家数据（背包/成就/统计）天然互不覆盖。

---

## 玩家看到什么

```
进空岛服
  ├─ 上次在某个岛上  →  直接回那座岛
  ├─ 有岛但人在别处  →  回他最近玩的那种岛
  └─ 还没有岛        →  落到大厅，点假人选岛型
```

选完岛型 → 自动建岛（虚空世界会铺出小岛，海洋世界会在海里找一块开阔水域放岛）。

---

## 两种岛型的区别

| | 经典空岛 `classic` | 海岛 `ocean` |
|---|---|---|
| 世界 | **虚空**（只有岛） | **自然海洋**（海洋/暖海/深海群系 + 沉船、海底废墟、珊瑚礁） |
| 岛的位置 | **网格方格**，每人格子固定 | **按距离摆放**，海里找开阔水域 |
| 岛面 | 草方块 + 树 + 箱子（含岩浆/冰/树苗） | 沙子 + 箱子（含钓竿/船/海带） |
| 掉下去 | 虚空，会被送回岛上 | 落海，自己游回来 |

**两种岛可以同时拥有**，归属记录也分文件存：

```
config/hubsuite/skyblock/islands-classic.json
config/hubsuite/skyblock/islands-ocean.json
```

## 配置项（`config.json` 的 `island` 段）

### 通用

| 字段 | 默认 | 说明 |
|---|---|---|
| `serverId` | `skyblock` | 哪个子服承载空岛（改这个要配套改子服配置） |
| `protectPlots` | `true` | 是否开启岛屿保护 |
| `autoCreateOnFirstJoin` | `true` | 首次进入岛屿维度时自动建岛 |
| `defaultType` | `classic` | 默认岛型 |

### 经典空岛（网格）

| 字段 | 默认 | 说明 |
|---|---|---|
| `plotSize` | `256` | **方格边长**。也决定岛的半径：`max(2, min(6, plotSize/64))` |
| `plotGap` | `32` | 方格之间的间隔 |
| `islandY` | `100` | 岛面高度（虚空世界里随便定） |
| `islandOffsetX/Z` | `0` | 整体偏移 |

> 方格坐标换算：方格 `(0,0)` 的中心在**世界原点**，
> 它的覆盖范围是 `[-plotSize/2 - gap/2, +plotSize/2 + gap/2)`。
> 默认 `plotSize=256, plotGap=32` 时，一格占 288 格宽。

### 海岛（海洋）

| 字段 | 默认 | 说明 |
|---|---|---|
| `oceanSpacing` | `320` | **岛与岛的最小间距**。要大于"岛直径 + 余量"，否则两座岛会贴在一起 |
| `oceanIslandY` | `0` | 岛的高度。**`0` = 跟着海平面走**（推荐），改成正数则固定 |

## 保护规则

| 位置 | 谁能建造 |
|---|---|
| 自己岛上 | ✅ 岛主 |
| 别人的岛 | ❌ 拒绝 |
| 经典空岛：**自己方格内**的空地 | ✅ 岛主（整格都算你的） |
| 海岛：自己岛之外的海面 | ❌ 公共区域，谁都不能圈 |
| 管理权限（OP / `hubsuite.admin`） | ✅ 放行 |
| 创造模式 | ✅ 放行 |

> **为什么经典空岛按"方格"而不是"岛的地形"判定**：
> 岛的地形只有半径几格，但方格有 288 格宽。
> 按地形判定的话，玩家在自己方格内走远一点就被拒绝建造 ——
> 实测出现过"箱子半边提示不是我的空岛区域"。

### 已知缺口

**爆炸（TNT / 苦力怕）和活塞不受保护**。默认 `plotGap=32` 时 TNT 半径够不到邻格，
但如果你把 `plotGap` 调得很小，就可能跨格炸掉别人的岛。

## 玩家指令

```
/island                   箱子界面（岛型 / 任务 / 返回大厅）
/island classic           去经典空岛（没岛就建）
/island ocean             去海岛（没岛就建）
/island home              回上次那种岛
/island hub               回空岛服大厅
/island info              我的岛信息（两种岛型都列出来）
/island types             列出所有岛型
/island reset <岛型>      重置我的岛（清归属重建，谨慎）
```

**只能进自己的岛** —— 没有邀请/串门机制。

## 常见问题

**Q：玩家的岛不见了 / 掉进虚空一直往下**
先看控制台有没有 `方格(x, z) 的区块还没加载，地形稍后补铺`。
地形是**延迟生成**的（海洋区块生成很重，不能在传送那一 tick 同步做），
系统会在玩家落到岛上后自动补铺。如果一直没补上，说明区块加载出了问题。

**Q：想重置某座岛**
```
/island reset classic     # 玩家自己重置
```
或者删掉归属记录（停服后）：
```bash
rm run/config/hubsuite/skyblock/islands-classic.json
```

**Q：想彻底重来（连地形一起）**
```bash
# 停服后
rm -rf run/hubsuite_skyblock_hub run/hubsuite_skyblock_classic run/hubsuite_skyblock_ocean
rm -rf run/config/hubsuite/skyblock
```

**Q：海岛太重，启动很慢**
海洋维度是自然生成的世界，首次进入某个区域要现场生成区块，这是原版行为。
`oceanSpacing` 调大不会更快，反而让岛更分散；调小则岛更密集。
如果服务器性能紧张，可以只保留经典空岛（把 ocean 维度从 `addDimension` 里去掉需要改代码，
或者干脆只用 classic）。
